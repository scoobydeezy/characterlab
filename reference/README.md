# Historical CharacterLab implementation

This directory contains the complete CharacterLab source tree as it existed immediately before the North-Star architectural refoundation.

Its purpose is historical inspection, reproducibility, comparison, and use as an explicit control implementation. It is not the active architecture and must not be imported by the fresh implementation under `../src/`.

Run the preserved test suite from the repository root:

```text
npm run test:reference
```

The original phase briefs, research log, and implementation README are preserved in this directory because they are research evidence and hypothesis/control sources, not current architecture.
