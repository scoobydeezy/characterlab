# Cognitive persistence projections and RNG ledger

Status: DRAFT. A successor to the currently qualified bounded no-RNG profile, not
promotion of PERSIST-I. Generic save schema and accepted addressed RNG remain unchanged.

## Public restore boundary

Retain the current public complete-S0/ordered-input-prefix restore discipline. A save
does not authorize injecting compiled handlers, private projection bindings, pending
facts or a caller-provided address set. The successor factory reexecutes the exact
committed model and prefix, validates the whole save and rebuilds private associations.
Mid-instant checkpoints remain excluded. No accepted old save changes interpretation.

State includes all predecessor roots, the373 successor's immutable plan map and the
new materialized identity-history leaf. Model identity includes their exact schemas,
roles, definitions, stage grammar, numeric profile, observation cut, trace and persistence
versions. Even byte-identical old leaf values cannot make old/new model identities aliases.

## Random-relevant authoritative IDs

The new projection is a canonical set of complete typed identifiers, deduplicated by
full canonical bytes. It is derived from the following closed state positions only:

1. CharacterId values in the retained immutable IDN roster.
2. CharacterId and task SemanticReferentId fields of each retained371 key in the
   commitment and adopted-instruction maps.
3. Each actual protocol action DefinitionId reached from a retained adopted instruction
   through its exact committed PlanInstructionDefinition. This is a declared model
   derivation from the retained reference, not a generic registry scan.
4. DecisionResolutionOccurrenceId from each retained identity contribution.

The first three cover persistent components used by future actor/action/task bindings;
the last covers retained causal roots of prior choice draws. Terminal tasks remain
in the projection while retained. Eligibility does not delete stable identities.
Qualifier occurrence IDs are evidence identities, not RNG address components in this
profile; they remain protected by full state canonical bytes and prefix validation.
Likewise prediction/observation IDs are not directly reinterpreted as random purposes,
subjects or roots. The new decision root comes from the separately saved shared allocator.

This is not a list of every historical consumed address. A zero-meaning contested
choice can consume draws but produce no retained identity entry. Its used address is
still reconstructed from the actual prefix/trace and protected by the private committed
ledger. Do not fabricate an authoritative identity contribution just to store that root.
The state projection and consumed-address ledger have different, explicitly named jobs.

Use the new set grammar only under the successor persistence profile. The predecessor's
empty no-RNG projection keeps its exact old bytes and scope. No semantic alias is asserted.

## Transaction-local oracle composition

At each instant create a fresh local oracle with the same committed run seed and any
profile-admitted comparison map. Reject a proposed address if its complete canonical
bytes already occur in the committed-address set. The local oracle rejects repetition
within that instant. Candidate attempts and mapped draw records remain pending until
the scheduler instant commits.

On success, append the instant's actual addresses to the private committed set after
all state/trace/queue/output validation succeeds. On failure, discard its oracle,
pending addresses and records alongside all other private facts. Shared allocator
rollback gives a retry the same resolution root and therefore the same natural draw.
No cache of mapped outcomes is an alternative source of randomness.

Restore derives the committed set by replay, checks each full draw transcript and
rejects a duplicate across the whole replayed run. The set is not a new save section
or caller parameter. Its derivability does not excuse stale state projections, changed
source occurrences, omitted prefix inputs or divergence in an earlier discarded branch.

## Actual PERSIST-I evidence required

At least one real generated two-option roll must execute before the save. Continue
from that save to another generated decision; compare state, queue, outputs, trace,
raw candidates, mapped faces, natural/effective addresses, identity application order
and allocator continuation against uninterrupted execution. Matching chosen action
alone is insufficient. Include an authentic no-meaning roll whose address is consumed
without entering retained identity history.

Mutate the saved random-relevant set, a retained decision root, a task/action binding,
run seed and prior draw/prefix data independently. Each must fail at its owning boundary.
Force a later same-instant failure after an actual draw, retry, and prove no address
was poisoned and all candidate bytes match. Retain duplicate-address rejection across
instant boundaries. None of the seven research adapter checks executes this complete
integration, so PERSIST-I remains DEFERRED/NOT PASSED until these controls run.

The first profile may keep externally supplied comparison maps excluded, provided
the qualification states that scope and retains the accepted substrate coupling controls.
Any paired experiment with differing local addresses must first admit and test an exact
coupling extension, rather than slipping a map into a closed ordered-input prefix.
