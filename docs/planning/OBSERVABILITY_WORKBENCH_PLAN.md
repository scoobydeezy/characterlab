## Required contracts

- Diagnostic identity includes run, model/seam version, canonical path or output
  identity and event revision. Preserve exact integers/rationals beside rounded plots.
- Authority (runtime, derived, evaluation, historical, diagnostic) and epistemic scope
  (world truth, character evidence/belief, diagnostic) are separate metadata.
- Runtime advancement stops at public quiescent boundaries. Timeline navigation may
  inspect committed internal stages without installing an intermediate mutable state.
- Fixture editing creates a new run. Runtime intervention requires an adapter's
  explicit supported command, validated ingress, immutable log and rollback checks.
  Adapters without that capability must not simulate it by changing live fields.
- Observed reads, value changes, evaluation contributions and controlled outcome
  effects are distinct. Unknown instrumentation is not negative evidence. No finite
  inactivity result authorizes removal.
- Input comparisons hold the model fixed; model comparisons declare the changed law
  and semantic correspondence. Both preserve exact originals, seeds and explicit RNG
  address coupling. Report identity, exact state and semantic divergence separately.
- Semantic projection versions and alignment rules are recorded. Missing events,
  unequal horizons and unsupported correspondence are explicit outcomes.
- Explanations use evaluation-time evidence only. Version the renderer and retain
  raw mechanical provenance. Unsupported language is an audit gap, not invented prose.
  Mechanical dice variance is not automatically epistemic uncertainty.
- Historical templates are never silently rerendered in place after a version change.
- Export includes inputs, profiles, comparison policy, hashes, selected evidence,
  coverage limitations and renderer versions; snapshots alone are insufficient.
- Resource limits must reject or explicitly truncate diagnostic retention; never
  silently drop events or change authoritative simulation work.
