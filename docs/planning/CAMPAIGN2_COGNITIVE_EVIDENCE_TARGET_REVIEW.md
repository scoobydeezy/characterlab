ReadDomain admission for each consumer. Character accessibility alone grants no lookup right.

## Recommended target for drafting

Make an observer-relative representation of a permitted measurement available to an explicitly
named cognitive evidence consumer, with exact source attribution and a traceable first content
difference. First investigate the evidence-carriage boundary itself; do not select a belief,
memory, appraisal, reward or performance update merely to force a downstream difference.

Hold observation identity/support topology fixed and vary only admitted measurement content.
Require any changed cognitive input to be explained by that content through the newly admitted
edge. Hold permitted content fixed while varying hidden D/truth and require identical cognitive
inputs. Suppression, missingness, other-observer evidence and unadmitted channels must not create
access by identity, hash, classification or metadata. Persistent character state can remain
unchanged during this initial evidence-carriage target.

The drafting pass must decide explicitly what counts as the target's positive result, including
whether it is only a prerequisite to ADAPT-9b. It must not declare ADAPT-9b passed merely because
a new serialized wrapper differs. Existing probe and EVID qualifications remain valid controls.
