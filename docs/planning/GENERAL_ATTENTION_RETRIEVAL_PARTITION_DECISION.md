# First ordinary recall resource scope

2026-09-12. **DECISION REQUIRED.** General Attention remains OPEN.

## What is already settled

Event/continuant and interoceptive acquisitions share ordinary-memory lifecycle and
acquisition addressing, with separately bounded acquisition and retention. Body evidence
must be genuinely recallable; it cannot live in a secret sample dictionary. Graph
learning remains event/continuant only. Actual direct cues are independent of graph
membership; retained evidence does not manufacture a current cue. None of these
rulings declares a common retrieval-slot budget or a cross-kind score scale.

Existing EAM top-K consumes one comparable score domain. The old public memory draft
contains only visual/event candidates. Body retained groups carry exact observations,
not visual strength, appraisal or importance fields. Adding them to a shared ranked
list would decide competition even if no new field appeared in the codec.

## Executed distinction

[Two actual ranker witnesses](RECALL_KIND_COMPETITION_TESTS_REV1.json) use supplied
numeric operands only, not public body cues. Event score .6 and body scores .4/.2 select
event under shared K=1. Rescaling body operands to .8/.4 preserves the body order but
selects body under shared K=1. Separate candidate partitions retain each kind's own
winner. This proves within-kind ranking alone does not establish shared comparability.
It is not a physiological or psychological scaling experiment.

## Alternatives

**A — separate bounded retrieval partitions first (recommended).** Declare independent
event/continuant and interoceptive recall candidate domains and slot budgets under the
same ordinary-memory service, with no borrowing or cross-kind score comparison.
Each branch needs an authenticated current cue and exposes only surviving retained
content. Event retrieval retains direct/spread controls; body retrieval receives a
separately specified direct signal-cue law, without creating body graph nodes. Exact
cue law, score and bounds remain shape work after the resource decision.

Both partitions must execute non-vacuous within-kind contention. Holding body cue,
retained state and retrieval operands fixed while adding event competitors must not
directly displace body recall, and vice versa. Their result union does not imply shared
workspace selection, simultaneous conscious presentation or a cognitive cross-kind
ranking. Any downstream common display/consumer needs its own declared input bound.
Preserve shared competition as a serious later control; A does not deny distraction.

**B — one shared recall budget now.** Explicitly authorize cross-kind competition and
define commensurate cue/accessibility contributions before implementing mixed top-K.
Body signal identity, sample count, interval width, pressure or arbitrary unit scaling
cannot stand in for the missing score semantics. Require normalization/calibration
and interventions that distinguish within-kind ranking from cross-kind allocation.
Existing same-kind scores alone cannot make that choice. No hidden physiological
truth or invented importance may supply it.

## Why this needs a ruling

A and B make different recall-availability predictions while preserving every accepted
formation, retention and graph contract. This is a resource-topology decision, not
an array layout or tie-break choice. A keeps the first body retrieval path bounded
without importing an unaccepted exchange rate. B is viable if shared retrieval
competition is now the desired phenomenon, but demands its own causal scale.

Neither closes presentation reinforcement, acquired protection, later affect feedback,
public source/owner/persistence qualification or corpus promotion. The bounded body
recall law and its read-only evidence boundary must still be specified and tested.
No retrieval policy, allocation or public source was implemented by these witnesses.
