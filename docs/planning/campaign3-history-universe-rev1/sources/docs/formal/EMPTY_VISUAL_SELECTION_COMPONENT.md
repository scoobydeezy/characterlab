# Empty visual selection from actual no-detection observation

`empty-visual-selection-component/0.1-candidate`, 2026-09-13. Local expression of
the existing positive/empty selection branch, not a new attention law.

The trusted source adapter supplies the observer, observation ordinal, instant and
empty detection array from an actually completed visual observation. Validate that
bounded structural shape and create an actual empty pool for the existing selector.
Do not synthesize a SemanticExperience merely to call the positive pool constructor.
The normal selector still owns the empty view and its one-use behavior.

A completed empty selection owes its actual audit/source enrollment but creates no
acquisition. No-detection source and zero-capacity positive source remain distinct
producer branches even though both can yield empty selected evidence. Pool creation
has no occurrence allocation, persistent state write, source authentication or public
ingress authority. The final public adapter must bind the actual observation and audit.
