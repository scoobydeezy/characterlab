# Position scene to actual observer experience

`position-scene-opportunity-component/0.1-candidate`, 2026-09-13.
LOCAL DISPOSITION — no owner ruling required.

Compose actual scene world materialization, one observation, optional event
detection, zero to three continuant detections, existing marker/event tracking,
perceived binding production and one conditional SEM-H freeze in either lane.
Only visible/permitted safe items become detection inputs. The source's actual
safe role enters the binding; no role is inferred from coordinates or glyphs.

Compile perceived binding requests for canonical order, then assign each actual
shared allocator result. Never assume that allocating one slot allocates an entire
binding batch. Truth, observation, detection, binding and experience slots are
distinct. For T true items and N visible items the allocation count is2+T when N=0,
otherwise4+T+2N. There is no experience or event-file occurrence when N=0.

The standalone scene requests no panel or body. It uses the existing uncontextualized
event-file law, rejects a present scene while an unsampled panel context is active,
and does not fabricate a missing panel to retire that context. Existing event and
continuant owners prepare candidates; neither publishes if any later local stage
fails. The enclosing runtime still owns allocator and whole-instant rollback.

The return's truth projection is trace-side only. Encoding preparation consumes
the separate observation/tracks/event/experience operands. Public source admission,
actual canonical occurrence extraction, role/content qualification, staged ownership
and persistence remain unqualified. This component is not a public model factory.
