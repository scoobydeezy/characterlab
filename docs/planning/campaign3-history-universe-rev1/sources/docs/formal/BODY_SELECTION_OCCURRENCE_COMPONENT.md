# Body selection occurrence binding

`body-selection-occurrence-component/0.1-candidate`, 2026-09-13. LOCAL DISPOSITION
— no owner ruling required. Implements the existing proposed BodySelectionAudit and
selected-view relationship; their new canonical record IDs remain unallocated.

An actual local-reserve opportunity passes the existing signal selector. The bounded
adapter additionally requires one to nine requested channels, one completed sample
per declaration, at most three signals and three views per signal, and positive
time. Existing channel/observer/time/producer/uniqueness and byte-limit checks still
apply. Missing sample records cannot be converted into observed Unavailable.

Every successfully completed selector allocates exactly one existing1143 occurrence,
including zero capacity and all-unavailable samples. The audit owns it; a one-use
selected capability carries the same identity. Consuming that capability yields
only its actual selected signal groups and safe sample bytes. It does not allocate
an acquisition, modify memory/protocol or authorize learning from a copied audit.
The later130 positive evidence producer remains the sole acquisition allocator.

Unknown body observations may have no shared experience; present samples require
the actual opportunity's experience under the existing source contract. A valid
numeric zero is still a present sample. Cue admission remains an independent
read-only consumer of the opportunity and does not require this capability.

BO-A freezes one1143 for positive/empty/unavailable selections and exact view binding.
BO-B preserves multiple views and separate signals. BO-C rejects incomplete source
bijection before allocation. BO-D protects forged/repeated/closed views and detachment.
BO-E protects allocation failure and exact retry; allocator rollback belongs to the
runtime. This component audit is data, not a new canonical record or public source
authentication certificate. Canonical roles, expected-parent attachment, actual PRJ
and protocol-hook registration remain public gates.
