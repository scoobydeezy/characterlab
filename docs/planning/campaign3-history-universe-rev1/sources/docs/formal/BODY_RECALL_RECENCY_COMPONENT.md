# Direct Signal / Acquisition-Recency Recall Baseline

2026-09-12. `body-recall-recency-component/0.1-candidate`.
Component shape accepted by primary-agent self-review under autonomous authorization.

Consume supplied surviving Interoceptive acquisitions, current cue Absent or Present
with1..16 distinct NFC signal symbols, current instant and body slot bound0..32.
Signal symbols are component stand-ins for qualified public identities. All retained
content follows retention-fragmentation-component's finite structural domain; original
acquisition times must be nonnegative and not future. Reuse only that component's
structural validation/detachment, not retention sorting or loss policy.

Eligibility is one Boolean per acquisition: any surviving group exactly matches an
admitted cue signal. No cue gives no candidates. Matching group/view count has no
weight. Rank eligible acquisitions by original acquiredAt descending, then canonical
unsigned acquisition identity bytes ascending for exact ties. Keep the body-slot prefix.
Return eligible IDs and detached recalled acquisitions with all surviving groups,
including co-acquired groups not present in the cue. Such remembered groups are not
assertions about current physiology. No missing group is reconstructed.

Repeated reads do not mutate memory, refresh time, reinforce accessibility or change
retention. Numeric sample intensity is not inspected and cannot remove a cue by being
zero. This component consumes the cue disposition; it cannot authenticate that a zero
sample supplied a lawful current cue. Its Absent branch inspects supplied memory for
structural validation; a public unavailable-cue facade must separately enforce its
declared no-memory-read behavior. Pure input inspection is not a public read grant.

No body graph, cross-kind score, pressure, presentation history or learned importance
operand exists. Acquisition-level results are not workspace/presentation events.
Public source permission/origin, subject binding, codecs, result identities and
persistence remain unqualified; component ordinals/strings allocate nothing.
