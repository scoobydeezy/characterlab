# Retained position-pair attribution

`retained-position-pair-attribution/0.1-candidate` — locally accepted bounded
component shape, 2026-09-13. Preserves the existing supplied-motion entry point and
its exact contrastive mathematics. Public source/projection admission remains open.

The inspected visual source supplies positions, not a whole motion in one stored
view. This successor binds each trial's motion to two separately retained EventContinuant
acquisitions, each with an exact child/view address admitted by the owner read domain.
The trusted projection returns observed time and a position0..7 squared or null.
Both acquisitions precede evaluation; observed time is nonnegative and no later than
its acquisition. Start observation strictly precedes end observation. Identical
acquisition identities reject in this first two-acquisition profile. No new motion,
episode or occurrence identity is allocated, and no old position is copied into a
new acquisition merely to provide the pair.

All supplied operands are domain-validated before evaluation; this does not credit
them as cognitive use. Semantic evaluation reads the starting position first. Null
or non-(0,0) starts stop before the end position and before the interval operands.
Otherwise the end position is consumed and the unchanged contrastive law continues.
Early Unavailable stops later trials. Addresses are deduplicated; successful finish
applies use only to the actually consumed children through the existing owner helper.
Opaque result binding, input detachment, one-shot finish and close behavior remain.

The focal target remains separately supplied and must not expand to both positional
operands. This component does not create focal membership or significance by itself.
General path integration and motion perception are distinct future candidates. The
first source's two observed positions suffice for its already accepted bounded rule.

acquisition time/order rejection; PP-D read-domain/view/kind exclusion; PP-E immutable
projection snapshot and one-shot result; PP-F invalid unread position rejects without
