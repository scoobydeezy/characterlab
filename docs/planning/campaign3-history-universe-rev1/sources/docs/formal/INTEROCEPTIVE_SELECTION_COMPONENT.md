# Interoceptive sample selection component

2026-09-12. `interoceptive-selection-component/0.1-candidate`.
**Component shape accepted by primary-agent review under autonomous authorization.**
No new canonical schema, production source, persistent root or allocation is accepted.

This is the equal-priority bounded control for the accepted separate body gate.
The candidate domain is0..3 actual-shaped EMB samples461/1 or463/1, from one observer
at one instant, with distinct observation identities and distinct observation channels.
Current producer version is exactly embodied-level-observation/0.1-candidate.
An absent sample463 is ineligible; a present sample461 remains eligible even if its
observed range would yield zero current pressure. Capacity is an integer0..2.

All eligible candidates have equal priority. Break ties by lexicographic canonical
channel-identity bytes, not input order, interval magnitude or occurrence ordinal.
This is an explicit tie convention, not a claim that channel names carry salience.
A future salience law must compete under a different contract/model. Duplicate
channels in one batch reject; the component does not aggregate temporal samples.

Validate and detach every input with the actual EMB canonical codec before selection.
Return a trace-side audit of observation identity and Selected/Capacity/Unavailable,
plus an opaque one-use view containing only selected canonical sample bytes. Consuming
the view returns fresh decoded copies, then revokes it. Forged, copied and reused
views reject. A view cannot be asked to resolve an unselected observation or old trace.
Closing without consumption revokes it. The audit is not a cognitive payload resolver.

Important boundary: canonical validation proves shape, not actual sensing, permission
or producer authenticity. Only a later governed public adapter can mint this component
input from live admitted outputs. No public factory or consumer accepts this view yet.
The source compiler must establish what distinct channels observe; this component
does not prove distinct physiological quantities or independence merely from channel IDs.

No visual input or budget is read. No pressure is recomputed or mutated. Selected
body sample values remain their exact original461 bytes; no encoding strength,
Need label, effect, causal inference, false zero or body-continuant identity is added.
The new durable representation still requires its own public contract and memory
access/retention semantics. This component is not a persistent body-memory sidecar.

Frozen component vectors: IB-A actual capacity0/1/2 and3-candidate contention;
IB-B added eligible competitors can displace the sole previously selected sample;
IB-C exact selected bytes and input-order invariance; IB-D absent/known-zero distinction;
IB-E malformed, foreign-observer, mixed-time, duplicate occurrence/channel and wrong
version rejection; IB-F source/copy/result isolation and one-use revocation;
IB-G independent visual selector competition does not alter the body selection.
Public source contention, retention, attribution and restore remain NOT PASSED.
