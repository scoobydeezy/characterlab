# Selected body context companion

`contextual-body-selection/0.1-candidate`, 2026-09-13. LOCAL DISPOSITION — no owner
ruling required. Composes body-selection-occurrence-component/0.1-candidate with
the existing proposed PerceivedTrialContextEvidence carriage.

A present companion must name the same actual shared experience, observer, instant,
event file and supporting panel observation as the source envelope. The panel sample
must be present with a valid observed glyph and stage. Exact plain data fields
exclude undeclared truth payloads and executable properties. These checks run before
selection allocation. Source authenticity remains an upstream obligation: matching
fields are necessary but do not make supplied records into genuine observations.

The context is detached into the same one-use selected capability. It allocates no
occurrence and cannot replace the selector's1143. Consumption releases selected
sample bytes and that bound companion, without exposing the full experience or
unselected samples. Absent context stays absent. An empty selection may still have
observed context, but it creates no child to retain it; context cannot make missing
signal evidence present or repair selection capacity.

CB-A compares actual observed source/context bytes; CB-B rejects cross-experience,
event, support, time and observer companions before allocation; CB-C protects
detachment/one-use and absent-context behavior; CB-E rejects undeclared/executable
companion fields; CB-D preserves empty selection with
no fabricated retained signal. This component does not authenticate arbitrary caller
data, define a new source version or qualify canonical body record codecs.
