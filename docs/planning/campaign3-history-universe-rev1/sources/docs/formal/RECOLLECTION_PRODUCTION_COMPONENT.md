# Recollection production

`recollection-production/0.1-candidate`,2026-09-13. LOCAL DISPOSITION — no owner ruling
required. Implements the actual winner-to-occurrence boundary in GA_RECOLLECTION_CARRIER_REV3.

Separate body and event preparation entries call the existing real rank kernels. The
subject is a trusted accepted PRJ/IDN projection, not inferred from observer text. A
completed absent cue performs no state-reader callback; available cues acquire their
declared subject state through the caller's admitted read boundary. Actual safe cue and
public read-domain authentication remain upstream.

The preparation snapshots actual winners into a private capability. Publication
consumes it once and allocates one distinct occurrence per actual winner, or none when
there are no winners. Content preserves the winning acquisition, original formation
time and surviving children/views. It does not reload an archive. Mutating a separately
returned evaluation cannot change what will be published. Failed allocation consumes
the capability; scheduler rollback of the allocator remains an upstream obligation.

Publishing returns observer-held recollections of the projected subject, with no memory,
graph, presentation, use or significance write. A later explicit presentation path is
separate. Public occurrence grammar, canonical codec/output descriptors, exact source
binding and cross-transition allocator uniqueness remain OPEN. No numeric allocation
is made by this component contract.

An explicit takeEventPresentation entry can consume the actual event publication
object once. Its private snapshot returns only observer, projected subject, instant
and recollection/acquisition pairs. Copying or changing returned publication data
cannot forge that handoff. Body publication rejects. Empty event publication yields
no presentation operations. This is a component causal binding, not public scheduler
authentication, a decision to present every recall, or a persistent mutation.
