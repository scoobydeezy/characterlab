# Independent current body signal cue component

2026-09-12. `body-signal-cue-component/0.1-candidate`. Component shape accepted
by primary-agent self-review under autonomous authorization. Public origin admission
and subject projection remain external obligations.

Input: current opportunity ordinal, ObserverId1000, exact current instant, bounded
channel1005→safe signal declarations, actual canonical embodied461 present /463
unavailable records, and a supplied permission Boolean. Record/interval grammar is
validated through the existing embodied codec. Require the exact accepted producer
version, same observer and current time, known unique channel and unique1115 unsigned
observation occurrence. At most16 signals,16 views each,256 declarations/samples and
65536 encoded source bytes per signal. Safe signal symbols are component placeholders,
not allocated InteroceptiveSignalId atoms. Bounds are safety limits, not cue priority.

Admit each signal with at least one present record iff permission is true. Denied,
only unavailable, or missing present observations yield no cue. Present zero-valued
intervals are not absence. Neither measured magnitude, acquisition capacity, selected
view, retained memory nor graph state participates. No durable selector is called.

Return a Present cue with canonically ordered distinct signal identities or Absent,
plus bounded provenance: existing supplied opportunity, observer, time and present
supporting observation IDs. No raw samples or source resolver is returned. Support
IDs are canonical copies; output provenance carries no dereference authority. No
allocator, persistent mutation, formation enrollment or learning transition exists.

This component checks supplied records, not actual runtime completion. An adversary
could supply shape-valid records with invented occurrence linkage; the public producer
must bind them to the exact completed same-run sensing output and accepted opportunity.
Current equality of timestamps alone does not do so. The supplied permission also is
not a public permission decision. Numeric-zero cue formation is tested with real record
codecs, but public observation provenance and PRJ/IDN remain unqualified.
