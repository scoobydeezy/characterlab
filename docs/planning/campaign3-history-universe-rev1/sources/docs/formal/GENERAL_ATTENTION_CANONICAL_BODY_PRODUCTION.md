# General attention canonical body production

`general-attention-body-production/0.1-candidate` serializes the existing completed
contextual signal selector and its one-use acquisition producer through the frozen
general-attention carrier allocation. It introduces no new selector, acquisition
gate, identity allocator, state family or provenance system.

The actual selector allocates one SelectionOccurrenceId/1143 even when no signal
qualifies. BodySelectionAudit/603 preserves that identity, actual observer/time,
optional shared experience and every signal audit row. Signal strings already bound
by the component are represented as InteroceptiveSignalId/1045; exact model member
admission remains with the profile compiler. No canonicalization operation selects
a signal or allocates an occurrence.

Only the completed private contextual selection capability can reach formation.
No groups returns NoFormation and allocates nothing. Positive groups allocate exactly
one AcquisitionOccurrenceId/1145 through the existing producer, then serialize its
actual samples and optional bound context into AcquisitionFormationEvidence/549.
The acquisition and selection identities remain distinct. Context uses the actual
panel occurrence, perceived event-file and experience; no new sensory occurrence,
trial ordinal, truth handle or causal answer is added. The panel version identifies
the existing trial-panel-source component that produced the sample.

The selector capability closes if canonical audit construction fails; producer
failure consumes its one-use capability. Allocator/trace/state rollback still belongs
to the outer whole-instant transaction. Source authentication, PRJ/IDN, exact member
roles, output slots and public model admission are not proved by this component.
All persistent character state can remain byte-identical after either output.
