## Closed source

The source is a plain object with exactly `parameters: Uint8Array`. Its canonical
value is `[version, law, goal, rehearsals, capacity, now, cue, report, worldAfter]`:
texts except unsigned rehearsal/capacity/worldAfter and signed now. Domains are the
existing continuation program domains. Exact reencoding is required; no unknown
fields, accessors, inherited configuration or coercion. Byte storage is copied by
intrinsics. Host properties attached to byte arrays are ignored, never executed.

The compiler commits the exact source and the complete native ModelID in a new
public ModelID, together with persistence/projection scope. Native ModelID commits
the inherited content, registrations, ownership, parameters and original S0. Public
RunID commits this successor ModelID, exact empty-acquired S0, ordered original
calendar and exactly32 zero seed bytes. Each run compiles fresh protocol/slot
capabilities. Only opaque prepared handles are accepted. Original bytes returned to
callers are copies; changed S0 or scheduled inputs are rejected rather than installed.
