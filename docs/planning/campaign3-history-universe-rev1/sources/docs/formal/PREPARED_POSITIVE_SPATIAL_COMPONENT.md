# Prepared positive spatial candidate

Version: `prepared-positive-spatial-component/0.1-candidate`.
Bounded implementation composition under the accepted immediate encoding and
separate prior-concern rules. No public registration or numeric allocation.

The baseline and prior-concern positive encoders consume a one-use
PreparedSpatialEncoding capability. Neither receives full source observations,
unselected witnesses, tracking state or a resolver. The existing selected-only
encoder owns strength evaluation; the existing positive projection retains exactly
Positive rows and each child's own binding/claim closure. Zero and unavailable rows
remain evaluation output only. The baseline convenience composition is preserved.

The prior-concern variant delegates subject/time/modulation checks to
prior-concern-spatial-encoding/0.1-candidate. Failure consumes the capability.
Feedback diagnostics remain on evaluation, never copied into positive child content.
At intensity1, intact peripheral strength is zero while focal strength is unchanged.
Disabling modulation preserves the baseline candidate exactly. The meaningful
coupled encoding comparator remains separate; no later outcome gates this encoding.

This component allocates no acquisition, mutates no memory or protocol root, and
confers no producer authentication. Public completed-parent, PRJ/IDN, source-audit,
formation ownership, canonical storage and persistence gates remain open.
