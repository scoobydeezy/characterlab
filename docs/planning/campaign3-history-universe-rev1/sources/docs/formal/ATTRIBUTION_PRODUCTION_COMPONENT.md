# Retained attribution result production

`attribution-production/0.1-candidate`,2026-09-13.
LOCAL DISPOSITION — no owner ruling required. Implements the narrow output role in
GA_GOAL_RESULT_CARRIER_REV3, consuming the accepted focal-position-pair calculation.

The context supplies an admitted earlier focal consequence and projected subject.
Absent focal consequence invokes no operand callback and allocates no result. Present
consequence with actually incomplete grouping produces an identified Unavailable
result with no consumed/target addresses. A complete operand set invokes the actual
focal attribution kernel once. Its real partial consumption survives Unavailable.

Supported output targets only the focal end-position child and verifies it was actually
consumed. No whole-acquisition/sibling credit is inferred. The producer drops the
kernel's diagnostic memory candidate and all metric/motion operands; output contains
only identity/subject/source/time/version, disposition, consumed addresses and targets.
No memory, use, goal, graph or significance state changes here.

Preparation snapshots the narrow result. Publication consumes a private capability
once and allocates one result for every present focal consequence, including semantic
unavailability. Failed allocation consumes the capability; actual scheduler allocator
rollback remains upstream. No permanent namespace is allocated by this component.

Operand construction is trusted composition of actual published recollections and
their safe context; it may not read unselected memory or a source archive. It binds
the focal index from perceived context and the actual consequence, never an authored
trial label. Exact public original/delivery/output/PRJ admission remains OPEN.
