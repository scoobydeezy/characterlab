# Combined panel, visual and body opportunity

`combined-observation-opportunity-component/0.1-candidate`, 2026-09-13.
LOCAL source composition of the eight cases in GA_BODY_SOURCE_BRANCH_CLOSURE_REV2.

This operation actually samples all three supplied channels at one instant: the
bounded panel display, one-position display and requested local-reserve channels.
It is not used to represent an unsampled channel. Allocate each actual observation
once, one event detection iff panel or visual is present, one continuant detection
iff the visual sample is present, and one existing experience iff any channel has
present evidence. Bindings receive their existing IDs only for actual visual tracks.

Panel and visual share the existing event-file owner. The marker transaction uses
the actual completed visual sweep, including an empty sweep when unavailable.
The source supplies no role observation, so its binding role is Unresolved; position
or panel stage cannot manufacture Actor. A later separately authorized role channel
must have its own actual source binding, not a free caller role parameter here.

Freeze SEM-H at the chosen lane's existing phase with exactly the present observation
support. Panel context, when present, uses that same experience and actual event file.
Only after successful preparation and freezing publish the marker and panel candidates.
On failure discard both proposals. Allocator rollback remains the enclosing runtime's
responsibility; no local allocator or duplicate provenance identity is introduced.

Outputs include actual sample/perception products for downstream compiler admission.
This trusted component has no PRJ, character state, selection, encoding, recall or
public source authority. The first four-trial profile does not automatically sample
all three channels merely because this combined operation is expressible. Its exact
requested-channel schedule and whole-prefix persistence remain packaging obligations.
