# General attention output and occurrence closure

2026-09-13. LOCAL DISPOSITION — no owner ruling required. Symbolic closure proposal;
no numeric allocation, public runtime qualification or whole-contract acceptance.

Reuse the existing transactional runtime ordinal allocator for the four new occurrence
roles: AcquisitionOccurrenceId, GoalOutcomeAssessmentId, RetainedAttributionResultId
and ProposedRecollectionOccurrenceId. Each has a nonnegative canonical unsigned
payload in its own as-yet-unallocated namespace. This is the accepted scaffold's
occurrence representation, not a new source/provenance counter or semantic ordering.
The model-local LocalReserveId and InteroceptiveSignalId remain separate identity
families with canonical nonempty NFC text; they use no runtime allocator.

## Allocation ownership

World materialization owns one existing world occurrence iff visual source is requested
and one existing event-binding occurrence per authored item, including hidden items.
Sampling owns one ObservationId per requested body channel, plus one for each requested
panel/visual surface, including unavailable observations. Actual visible visual items
own detection occurrences. A present panel or nonempty visual detection set owns one
event-detection occurrence. At least one actual safe supporting observation reserves
exactly one ExperienceId before binding; freeze reuses it, and neither modality gets
another experience. Inherited SEM identities and file counters retain their contracts.

Tracking allocates no runtime occurrence. It may advance existing observer-owned
continuant/event file counters. Binding owns one perceived-binding occurrence per
actual tracked item. Homogeneous classification emits no result. Role derivation owns
only actual derived claims. No end-of-event result gets a made-up fresh identity.

Each completed body/visual selector owns one existing1143, even when empty. Its selected
view borrows that occurrence. Encoding/positive projection allocates nothing. Each
actual successful body or visual formation owns one acquisition, irrespective of its
number of groups, views or semantic children. No140 owner allocates again.

Every real rank winner gets one recollection in its publishing transition. Empty and
unavailable rank outputs allocate none. Goal baseline and ordinary body recall are
separate evaluations and may lawfully recollect the same acquisition independently;
they do not share or reuse a recollection occurrence. Presentation reuses actual
recollection/acquisition references and allocates no additional occurrence.

Goal assessment owns one result iff an actual consequence experience exists, even
when the assessment is unavailable. Retained attribution owns one result iff the
focal consequence exists, even when recalled operands or grouping are unavailable.
Neither absent branch invents a placeholder occurrence. Use/significance/delivery and
retention wrappers borrow their actual evidence identities. They have no parallel
provenance family. Prior workspace/appraisal/concern reuse1128/1129/1130 unchanged.

## Envelopes and inherited admission

CompletedRequestedSamples and other transport/derived records do not own an occurrence
merely because they are outputs. Their nested observations/reservation are checked
against actual allocated slots; freeze checks its reserved slot separately. Reuse the
existing required-top-level occurrence extractor for identity-bearing records, and
explicit nested slot validation for transport envelopes, as the accepted attention
runtime already does for detection children and reserved experience. Do not force
every transport through the old V04 mandatory-one-output/one-occurrence rule.

This still requires the exact successor registration/output descriptor and adapter:
generic schema membership alone proves neither allocation ownership nor freshness.
No output may be admitted solely because its identity belongs to the right namespace.
Input/producer association, cardinality, actual slot equality and rollback all remain
required. An emitted acquisition that immediately loses all children is still a real
committed formation; its protocol history preserves that fact without retained payload.
