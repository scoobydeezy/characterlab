# General attention: outcome-dependent encoding lifecycle decision

2026-09-12. **OPEN architectural decision.** General ATTN-001 remains OPEN.
No accepted seam, numeric allocation or production implementation changes here.

## Why the current recipes cannot close General Attention

The32 draft recipes keep Need and surprise Disabled and use a homogeneous category
prior. They can test selected encoding, association/access and delayed TaskConcern
feedback, but cannot satisfy all MEC-007/EXP-007 obligations merely by being implemented.
Category evidence and positive Cause/Incidental also remain source debts.

Read-only inspection of reference/src/model/salience.ts confirms that historical Need
relevance uses urgency times the magnitude of a realized regulatory effect, only for
concepts causally connected to that outcome. Surprise compares a prior estimate with
permitted point/lower-bound/upper-bound evidence. Correct censored-evidence handling is
mandatory; raw clipped discrepancy and truth Overflow remain prohibited shortcuts.
Historical EffectProvenance cannot be imported as observer-safe causal evidence.

The current profile supplies an earlier diagnostic measurement and present three-port
scenes. It supplies neither this event's experienced regulatory effect nor observer-safe
unit/effect connection evidence. TaskConcern cannot be renamed Need relevance or
surprise. Doing so would violate both the retained non-Need distinction and the
requirement to consume actual permitted evidence.

## The concrete lifecycle choice

The draft selects and evaluates encoding at40, retains at130 and forms immutable
episodes in the140 sibling batch. Accepted EVENT_ORDERING places consequence experience
freeze at124 and outcome evaluation/learning evidence at130. A current event's observed
outcome therefore cannot already have determined encoding at40.

For events perceived before their consequence, decide whether that consequence
determines the first durable encoding or produces a later consolidation record. This
changes admitted carriers, episode lifecycle, trace ancestry and batch target handling.
It is not a calibration choice. The public memory shape should not be allocated while
silently leaving this requirement outside its intended lifecycle.

### A — Defer durable encoding for consequence-bearing episodes (recommended)

Keep selected evidence provisional. A separately accepted observer-safe salience
assessment consumes the actual consequence, admissible prior and explicit unit/effect
connection evidence. Compute final encoding afterward, then produce one retained
encoding and one formation triple at140. Current-only scenes retain their explicit
outcome-independent path.

This preserves immutable historical factors and one formation per target. It provides
no durable episode for that event before its expected consequence. Missing/unavailable
consequences need an explicit completion rule, not invented zero or abandoned work.
A first bounded profile could restrict the outcome to the same instant; across-instant
deferral would need a new pending carrier/save rule.

The new assessment is separate from accepted EVID OutcomeEvaluation, whose conservative
fields do not silently acquire appraisal, utility, causal attribution or surprise.

### B — Encode immediately, then append outcome-linked consolidation

Keep initial encoding independent of the outcome. Later observer-safe assessment
produces a new append-only record linked to the episode. Original bytes remain intact.
Retrieval must explicitly define how initial encoding and later consolidation affect
current accessibility and associations.

This permits recall before the consequence and preserves an inspectable evolution,
but requires a new consolidation record/lifecycle and association-update rule. If both
stages occur in one instant, the barrier must reconcile their target rather than run
two independent writes to the same character leaf. Later salience cannot be relabelled
as the original episode's historical encoding strength.

Neither option authorizes stronger outcome truth, raw-observation learning, TaskConcern
as a Need, new EVID semantics or an unreviewed belief read/write order. Both need a new
observer-safe effect/connection/assessment seam. After the lifecycle choice, that seam
and the remaining category/causal-role sources can be designed and reviewed autonomously.
The options make different memory predictions; the authorities do not select between
them for this new public contract.
