# First acquired retention-protection candidate

2026-09-12. **Historical decision packet; A subsequently accepted.**
See [accepted ruling](GENERAL_ATTENTION_USE_PROTECTION_RESOLUTION.md) and
[remaining consumer decision](GENERAL_ATTENTION_USE_CONSUMER_DECISION.md).
The proposal below records the state before that ruling.
The Recency Retention Baseline ruling requires a richer protection/reinforcement
candidate before broad ordinary-memory qualification or GA closure. It expressly leaves
the qualifying evidence, unit of credit and update law undecided. This is not optional
future polish and cannot be filled by reusing a presentation count.

## Existing authority and available evidence

Original acquisition time, surviving semantic children and stable acquisition IDs exist.
Actual recall can expose surviving content. That exposure alone does not prove downstream
use or significance. The accepted outcome-attribution path establishes eligibility only:
Supported is neither measured benefit nor permission to protect a memory. No current
public receipt authenticates a retention-relevant use. A proposed use receipt therefore
requires a separately registered consumer and exact completed-output/operand binding.

Current cue admission remains read-only and creates no learning transition. Recall
recency and presentation accessibility are separate from storage survival. Governance
history is protocol state and may never supply psychological use or importance facts.

## A — bounded binary protection from authenticated downstream use (recommended first)

Introduce a separately versioned retention-control hypothesis: an actual declared
downstream consumer's successful use of surviving semantic units can set a unit-local
UsedProtection flag. It starts false. Credit names the existing acquisition/child
address and only the units demonstrably used, not every co-acquired group by default.
It is separate metadata, never a rewrite of original encoding bytes or AcquiredAt.

Qualifying use requires an accepted consumer with a defined cognitive task beyond
retrieval bookkeeping. Merely appearing in a candidate list, returning a recall result,
logging/displaying a diagnostic, refreshing presentation history or issuing a query does
not qualify. The receipt must bind actual admitted retained operands and that consumer's
completed result; a caller assertion that content was useful is insufficient. Exact
consumer choice/admission still needs a contract before public execution.

Under within-kind retention pressure, preserve protected units before unprotected
units, then use original acquisition recency and existing deterministic ties within
each tier. Every surviving unit still costs one slot. Repeated uses do not accumulate
points or refresh age: false→true is the only effect. Protected units still compete;
when they exceed capacity, the existing within-tier ordering loses some. Zero capacity
loses all. This is not a guarantee of permanent survival, nor a theory of importance.

No retained unit or receipt resolver survives complete child loss; protection cannot
resurrect content. Pure recall rehearsal cannot bootstrap credit. A later actual task
may legitimately use recalled content, but must satisfy the explicit use contract.
Same-barrier use/retention timing, exact receipt idempotency and owner-result ordering
must be frozen before implementation; do not infer a transient access window.

## B — graded use reinforcement now

Authorize a separately bounded quantitative protection variable updated by authenticated
uses, potentially decaying with time. This can distinguish repeated from one-time use,
but needs exact accumulation, saturation/decay, same-instant composition and units.
It cannot borrow MEC-010 accessibility values or current recall rank as survival strength.
Evidence/credit locality and self-rehearsal controls still need explicit contracts.

## Distinguishing predictions and limits

With capacity1, old used alpha at t1 and new unused beta at t8: recency retains beta;
A retains alpha. If both are protected, A reverts to their original-time order and may
lose alpha. Repeated use of alpha creates no further advantage under A, while an
appropriately specified B may predict one. These are proposed model predictions,
not executed use-production witnesses.

Required comparison cases remain: old used versus new unused; attempted self-rehearsal
feedback; and old rarely retrieved but strongly outcome-consolidated content. A alone
does not explain the third case. Outcome-derived significance requires its own permitted
assessment/effect law; supported attribution cannot substitute for it. Neither A nor B
automatically closes that obligation or all of General Attention.

Recommendation A earns a minimal explicit use→survival distinction before adding a
continuous memory-strength variable. Preserve recency-only as the baseline and B as
the richer competitor. The requested decision is the binary, unit-local, actual-use
direction and tiered survival rule—not public qualification of an unspecified consumer.
No protection field, use producer or new learning write has been implemented or allocated.
