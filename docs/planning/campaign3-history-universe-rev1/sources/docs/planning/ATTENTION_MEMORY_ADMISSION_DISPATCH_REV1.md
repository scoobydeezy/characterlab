# Attention memory admission and dispatch inventory

2026-09-12. Draft finite registration semantics; not canonical registration acceptance.
The machine packet joins the corrected22-stage graph, explicit wrapper fields and
output/slot inventory. It also declares five mutually exclusive phase140 batch shapes.

All generated inputs require an exact trusted expected-event association before
projection or state reads. Correct record shape, matching event time, allocated parent
identity or a copied Subject alone is insufficient. Parent/output/observer/target
equality and transaction-local once-only consumption remain separate checks.

Encoding and recall joins, rank, and each character writer perform accepted PRJ/IDN
through the required scalar ObserverId on their actual admitted wrapper. Their copied
Subject, when present, must equal the result. ObserverId namespace membership alone
does not validate CharacterId; the existing character-content domain role remains
required. Perception state remains keyed by the actual source observer; memory leaves
are keyed by the qualified character. No generic state enumeration is granted.

Formation has three authenticated siblings, all carrying the same FormationInput and
actual retention parent. They write only EpisodeLedger, AssociationGraph and
PresentationLedger respectively. Seed and reinforcement share one presentation owner.
Each member reads its expected-old leaf from the common B0. Candidate patches must be
validated under their individual authorities and qualified targets, checked for
overlap, then composed and checked for cross-leaf consistency before publication.

The dispatcher accepts exactly one of: existing measurement/prediction/task triple;
its complete padding triple; the attention formation triple; attention reinforcement
singleton; or task deadline singleton. Mixed, duplicate, incomplete or extra members
reject. Equal time is not a substitute for common authenticated parentage. Source
and attention lifecycle managers still need their own pending-association checks.
No phase140 member emits work. Failed instants discard all proposed consumption,
patches and tracking proposals along with the scheduler candidate state.

This is an explicit successor dispatcher proposal. It neither broadens the current
Campaign2 membership checks nor removes their preflight barriers. The earlier source
at0, read/concern at1, receivers2..9 and deadline20 grammar is still a model gate;
the dispatcher cannot silently handle overlaps that grammar was meant to exclude.

The review checks field expressibility, required projection presence, writer ownership,
parent sets, and exact dispatch membership. Ten deliberately corrupted packets reject.
These are design checks, not actual public admissions, canonical owner patches or
runtime mutants. The scheduler fixtures from the previous checkpoint remain their
separate bounded evidence. No new allocation, runtime behavior or corpus claim occurs.
