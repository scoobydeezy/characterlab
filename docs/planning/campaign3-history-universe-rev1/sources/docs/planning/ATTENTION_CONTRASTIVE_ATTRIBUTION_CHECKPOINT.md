## Implemented and reviewed

The [component contract](../formal/CONTRASTIVE_ATTRIBUTION_COMPONENT.md) names
`contrastive-attribution-component/0.1-candidate`. It tests a fallible repeated
motion/stationary contrast: two trials of each kind, identical observed starting
intervals, and strict conservative separation of subsequent level-change intervals.
Only Supported/Unavailable is produced. There is no confidence, effect magnitude,
belief lookup, persistent write or conscious-belief prerequisite.

The rule adds replicated contrast beyond simple temporal proximity, but cannot
exclude hidden confounding. It is a candidate implicit attribution mechanism, not
proof of actual intervention efficacy. Net observed change remains distinct from
Applied and from pressure relief. The stationary cases are part of its evidence
basis; selecting only favourable trials is forbidden in eventual source admission.

Revision1 preserves the earlier test run before the explicit unbalanced-count case.
[Adversarial review](CONTRASTIVE_ATTRIBUTION_REVIEW_REV1.json): six actual in-memory

interval endpoints, ignored baseline, ignored replication, omitted positive-change
requirement and sparse-coordinate admission. Source files were not replaced on disk.

CA-H establishes only function-level equality for identical supplied operands with
different hypothetical hidden explanations. It does not qualify an actual public
false-attribution source. That stronger obligation remains open. The component's
positive result cannot authorize any memory write on its own.

## Integration work prepared and remaining

The contrastive source needs retained pre/post body evidence and observable movement
for the same perceived candidate. Existing marker continuity is fallible and may be
reused only through its authentic producer; it is not proof of a causal relation.
No raw truth or occurrence ordering can choose the target or match the trials.

SEM222 has exact event feature values but the current closed feature vocabulary has
no general contact or stroke primitive. Prior position proposals expose one coordinate
per detection. A source describing a motion segment requires exact permitted
observation semantics, not a caller-authored Supported flag or an arbitrary pair of
unrelated snapshots. No such public feature source has been implemented here.

The next integration also needs a disposition for body evidence entering durable
memory. Appending numeric body samples as an unrestricted companion to selected
visual content would bypass the current positive-retention boundary. Manufacturing
an event-file/body continuant or causal role to fit the old key would redefine SEM.
The [interoceptive encoding decision](GENERAL_ATTENTION_INTEROCEPTIVE_ENCODING_DECISION.md)
therefore fixes the concrete capacity/topology choice before new source records.

No permanent allocation, public model, source admission, history store, consolidation
write, restore qualification or corpus promotion occurred. No historical mechanism
was retired. The prior public attention preservation receipt remains independent.
