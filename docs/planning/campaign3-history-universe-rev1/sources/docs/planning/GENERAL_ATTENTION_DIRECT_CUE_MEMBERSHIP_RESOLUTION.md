# Direct episodic cue matching: A accepted

2026-09-12. **CUE/GRAPH SEPARATION ACCEPTED by supplied planning ruling.** Resolves
the [decision packet](GENERAL_ATTENTION_DIRECT_CUE_MEMBERSHIP_DECISION.md). Exact
numeric composition, public cue admission and graph scarcity remain open.

A lawful current cue can directly match currently retained episodic content whether
or not its semantic key exists in the persistent learned graph. Learned associations
provide a separate propagation path. Graph membership is not a cue-permission bit.

The cue's zero-hop contribution belongs to DirectMatch and is counted exactly once.
LearnedSpread represents additional influence mediated by learned structure. Since
the existing solve `a=(I-beta W)^-1 b` already includes b, adding all of a beside a
new direct term is prohibited. The ruling fixes this semantic invariant, not a new
weighting, quantization or numerical factorization. Those need their own reviewed
component/public contracts and no-double-count controls.

## Membership and authorized evidence

| Membership | Authorized possibility |
|---|---|
| Episodic and graph | Direct matching plus learned propagation |
| Episodic only | Direct matching without inserting learned state |
| Graph only | Real current cues may seed learned propagation; no episode target is manufactured |
| Neither | No episode target or learned contribution from membership alone |

Retained content does not itself produce a cue. Direct matching and graph seeding
require actual admitted current cue evidence; hidden truth, trace, old source payloads
and discarded memory cannot manufacture one. A cue for a graph-only key may influence
surviving related content without reconstructing the forgotten episode.

## Working domain is not state

An evaluation may use the union of retained episodic and learned graph keys, representing
episodic-only keys as temporary isolated vertices. Equivalent factorizations are allowed.
These working vertices allocate no identity, insert no persistent nodes, create no
learned history, consume no graph-retention capacity and do not survive evaluation.
Work/byte bounds still apply to the computation independently of cognitive capacity.

Deleting an isolated learned node must not disable direct matching of independently
surviving episodic content. This does not authorize automatic orphan pruning or decide
node/edge accounting, graph survival priority, weakening or replay policy.

## Required proofs — frozen, not passed by earlier tests

1. Hold surviving content and admitted cue fixed while adding/removing its matching
   isolated graph node. DirectMatch is exactly equal.
2. At W=0, graph machinery plus direct matching has the same cue-derived contribution
   as direct matching alone, never double the cue effect.
3. Cue a graph-only key linked to a retained key: learned propagation can change
   ranking while the graph-only key remains non-recallable.
4. Temporary union membership has no persistent write, allocation or graph-capacity
   consequence, and never admits a fabricated cue or removed payload lookup.

The earlier11 component tests expose the old coupling and validate a graph-contribution
adapter. They do not yet pass the newly accepted combined DirectMatch/LearnedSpread
contract. That adapter remains a valid graph-only contribution component; it is not
the complete direct-cue path or a public cue source.

Preserve graph-membership-gated direct cueing as a named coupled control, not the
intact successor. Independent association lifecycle, episodic loss and acquired
protection obligations remain unchanged. General Attention remains OPEN.
