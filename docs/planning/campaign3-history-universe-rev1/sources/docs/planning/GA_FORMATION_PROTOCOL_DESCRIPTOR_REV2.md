## Payload-free owner projection

FormationOwnerDisposition contains a map of this batch's QualifiedFormationSource to
FormationSuccess and a set of newly complete-loss acquisition identities. The map
includes immediate total loss of a new formation. Existing partial loss adds no loss
entry. Prior true loss never reverses. No survivor child list, encoding content, sample
or candidate archive crosses this boundary.

This is the fixed adapter's projection of its actual validated owner result, not a
publicly accepted free-standing command. The transaction binds the owner result to
the exact batch before projection and to the hook consumer before use. There is no
OwnerResultId: result object identity is transaction-local authentication only, never
saved authority. Complete-prefix validation reconstructs these facts from the admitted
run and canonical state/queue on restart.

The final protocol validator compares prior and candidate maps against the actual
admitted sources and owner disposition, enforcing monotonicity, exact immutable success
metadata and no invented success/loss. Generic expected-old patch checks alone cannot
prove those relationships. Any failure rolls back both protocol and ordinary memory.
