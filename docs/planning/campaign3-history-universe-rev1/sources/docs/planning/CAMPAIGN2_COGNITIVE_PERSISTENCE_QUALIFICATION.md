## What is reconstructed

The public factory admits only plain copied byte fields. Restore prepares the exact
committed model and reruns original S0 and ordered inputs with the saved RunIdentity
seed. It stops at the complete committed trace length, rejecting exhaustion, failure
and crossing an instant boundary. The entire freshly produced canonical save must
equal the supplied save. Only that replay instance is returned. Imported state,
queue, allocator or trace is never installed as an alternative authority.

This validates state, run/model identity, clock, queue, allocations, all three
metadata projections, trace and semantic outputs by exact equality. It also rebuilds
the genuine source associations and consumed-address ledger through execution. No
caller-provided cache, handler, projection, private association or address list is
accepted. A failed object remains terminal; retry means a new authenticated replay.

The state-derived random-relevant set is separately and exactly the frozen traversal:
IDN CharacterIds; retained task-key CharacterIds and task referents in both maps;
actual protocol-action DefinitionIds reached through those immutable instructions;
retained DecisionResolutionOccurrenceIds. Whole typed identities are canonically
deduplicated. Qualification IDs and observation references do not become RNG roots.
An authentic zero-meaning roll can leave no identity entry while its used address
still belongs to the private ledger rebuilt from the complete prefix.

The implementation derives RNG outcomes from accepted addressed randomness. It does
not restore a table of outcomes or serialize a new private-ledger save section.
Resolution identity is reserved from the shared allocator before draws. Candidate
addresses publish only after whole-instant validation; failed local oracle state
cannot poison future reconstructed draws.

## Deliberate exclusions and reopening

Mid-instant saves, imported learned S0, externally supplied comparison maps,
multi-character coupling and arbitrary live handler restoration remain excluded.
The substrate's existing coupling mechanism and tests remain intact. Paired runs
with different natural addresses must not be described as coupled merely because
their seeds match. A map-enabled successor needs explicit admission and persistence
proof. Prefix replay is intentionally bounded and is not a scalable checkpoint
optimization or a general provenance graph service.

Reopen on changes to RNG subjects/purposes/roots, authoritative ID traversal,
source graph, model/ordered-input profile, state ownership, save boundary or permitted
coupling. Existing save/model versions remain immutable. Evidence and current hashes
are indexed in COGNITIVE_QUALIFICATION_EVIDENCE_REV1.json.
