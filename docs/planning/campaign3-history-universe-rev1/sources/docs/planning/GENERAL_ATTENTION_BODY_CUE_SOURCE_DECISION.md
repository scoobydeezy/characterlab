# Current body cue source: acquisition coupling decision

2026-09-12. **DECISION REQUIRED.** Exact signal matching, acquisition-level recall,
recency ordering and separate retrieval partitions remain accepted. The public producer
of the lawful current cue is not fixed by those laws.

## Inspection

interoceptiveSignalSelection consumes actual bounded observed sample records, groups
them by governed safe signal declarations, and returns selected groups under durable-
acquisition capacity. The source and the selected view are distinct. A permitted
observed signal can therefore exist without entering durable acquisition. The current
body recall component instead consumes an already-admitted Present/Absent cue and
does not authenticate its origin. Reusing the selected view is possible but would
introduce acquisition-selection → recall-cue availability as a causal dependency.

The accepted cue law prohibits self-cueing and requires actual current safe evidence.
It does not state that evidence must also win durable encoding. Conversely, permission
alone is not a completed cue: neither alternative may invent a cue without an actual
source occurrence and explicitly admitted cue evaluation.

## Alternatives

**A — separately admitted current signal cue, independent of durable-acquisition
selection (recommended).** An explicit bounded recall-cue opportunity consumes current
observer-safe signal evidence from its real admitted observation producer and governed
channel-to-signal projection. It may name a signal that did not win durable acquisition.
It still requires its own cue permission/eligibility, exact completed source, observer,
time and subject binding. No automatic cue is emitted merely because sensing is allowed.

Thus reducing durable-acquisition capacity to zero can prevent a new memory while a
separately admitted current cue recalls an older surviving acquisition. Do not give
cue evaluation write access or implicitly form a new acquisition, enroll a phantom
formation source, or expose physical reserve keys. The cue stores only the safe signal
identity and accepted provenance; raw samples never become an archive resolver.

**B — current cue requires winning the durable-acquisition selection gate.** Only an
actually selected current signal group can supply a cue. Hold old memory and actual
observations fixed: reducing acquisition capacity can suppress recall by excluding
the relevant signal. The successful cue does not itself require new formation success,
but it requires selection. This shares one scarce gate across new acquisition and
access to old body memories. It is a coherent stronger coupling, not an identity rule.

## Discriminating public experiment

Retain an old alpha acquisition. Supply a real current permitted alpha observation
and an explicit recall opportunity. Set durable-acquisition capacity to zero while
keeping recall slots positive. A can recall the old acquisition under separate cue
admission; B cannot produce alpha's cue. Then enable acquisition selection and require
the distinction to collapse. This is a proposed public witness, not an executed source
test; current component cues were supplied directly.

For either option, numeric-zero observations remain eligible evidence as declared by
the cue producer, while unavailable/denied/no completed source gives no cue. Wrong-
observer, stale, copied provenance and physical-key inputs reject. No remembered
content or old source ID can synthesize fresh evidence. Interoceptive graph and
presentation reinforcement remain excluded. Reuse actual sensing opportunity identity
where its contract permits; do not allocate a second sensing occurrence by assumption.

Recommendation A preserves the separation of durable acquisition and access to prior
memory. B remains an explicit shared-gate control. This choice changes a causal edge
and potentially recall behavior, so it must not be buried in producer wiring. Public
source schema, exact permissions and work/byte bounds follow the ruling; no new
source mechanism, numeric allocation or public cue implementation is made here.
