# Active Research Planning

These ledgers turn the North Star, canonical architecture, formal contracts, and historical evidence into explicit campaign inputs.

Active sequencing is owned by the [Reference Architecture Build & Research Campaign Plan](../../CharacterLab%20%E2%80%94%20Reference%20Architecture%20Build%20%26%20Research%20Campaign%20Plan.md).

- [Seam ledger](SEAM_LEDGER.md) — formal readiness and earliest unproven boundaries
- [Reference mechanism preservation ledger](REFERENCE_MECHANISM_LEDGER.md) — port, control, corpus, candidate, and retirement obligations from the previous CharacterLab
- [Phenomenon corpus](PHENOMENON_CORPUS.md) — stable behavioral and causal obligations
- [Verdict ledger](VERDICT_LEDGER.md) — active reduction evidence and reopen conditions
- [VAL-001 revision 2](VAL_001_DRAFT_RESOLUTION.md) — governed executable commitment, separate content-kind/domain-validator definitions and exact coverage; shape and allocation accepted, implementation qualification pending

A build or campaign plan may sequence work only after identifying the applicable entries in all four ledgers.

[Campaign-2 factory design](CAMPAIGN2_FACTORY_DESIGN.md) records the accepted construction/restore implementation design and its explicit readiness items.

[C2-PERSIST-001](CAMPAIGN2_PERSISTENCE_CLARIFICATION.md) records the shape-accepted save-metadata profile; concrete first-model binding and implementation qualification remain.
