or alternate routes through bounded ordinary planning. Two observers infer the desired
state from their own perceived attempts and achieved locations. Goal, strategy,
attempt, outcome, admitted evidence and inferred goal remain separately traceable.

destination, while two different paths can reach the same destination. It does not
inject an inferred goal label. This is not general inverse planning, learned action
recognition or candidate-goal discovery. Adoption140 affects only later planning90;
failed execution leaves the adopted goal intact. Standing repeated delivery does not
qualify fulfillment/termination or a general persistence law.
