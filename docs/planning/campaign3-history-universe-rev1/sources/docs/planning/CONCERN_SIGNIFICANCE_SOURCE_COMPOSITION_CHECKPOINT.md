  The SEM allocator authenticates its own file allocation, not the sensory cue source.
- Retained views use fixture JSON, not an allocated canonical public child schema.
- Body recall uses actual retained groups and a later actual safe sample's signal;
  public completed-sensing/cue carrier authentication remains open.
- Event children are supplied as admitted reads; general event recall admission is
  not exercised by this fixture.
- The focal role is chosen explicitly by the fixture schedule. An actual admitted
  focal-opportunity producer and consequence/target binding remain required.
- Concern qualification is computed at the consequence and kept as a local value.
  Goal withdrawal executes, but immutable result delivery, scheduler commitment and
  restart persistence are not established here.
- The newer used competitor is a supplied comparator premise. Formation occurs
  before any credits, so the fixture's initialization of fresh metadata does not
  establish a general preservation law for later formation into credited memory.
- No public factory, allocation, corpus member or GA completion is promoted.
