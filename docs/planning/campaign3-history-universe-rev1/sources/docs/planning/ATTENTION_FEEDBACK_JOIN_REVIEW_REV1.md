# Attention delayed-feedback join review — revision 1

2026-09-11. DRAFT integration refinement. This addresses an actual ordering gap in
the source/concern sketches; neither draft is a whole accepted public contract yet.

## Why simple delayed carriage is insufficient

A delayed carry and the later observed scene are distinct causal parents. Copying
the carry into a runtime closure without a declared join would hide an input; adding
a made-up phase39 would violate the frozen phase inventory. The source graph must
name the two-parent association, its input schema and output binding explicitly.
The accepted parentTaskConcern occurrence alone is not proof that a caller-supplied
carry belongs to the receiving run, instant or observer.

## Proposed first chronology

1. At an earlier original instant, execute the accepted regulatory probe → observer-safe
   measurement carriage → actual measurement-prediction update. This supplies the
   forecast through the existing character-learning route; no authored forecast is
   substituted into S0. Read actual task commitment/status under its existing contract.
2. At the next exclusive original instant, execute actual workspace381 → appraisal384
   → concern388 with one selected task. The new bounded producer profile stops at
   concern; it does not claim to execute the complete cognitive choice/action model.
   Pure transformations are reused beneath new actual registration/admission, not
   called on arbitrary public workspace/appraisal records. Existing complete cognitive
   models, dice grammar and their evidence remain unchanged.
3. The concern adapter generates the narrow carry for the next committed scene instant.
   Carry delivery is at existing phase15; no new phase is allocated. The scene still
   begins at phase0 and completes its permitted observation/SEM staging before40.
4. A named join at phase40 requires both actual registered scene/selection-side parent
   data and the delivered carry. The join's exact dependencies and receiver binding
   precede modulation/selection/encoding at that phase. The join produces a restricted
   character-side operand, never a task workspace or archive capability.
5. Consolidation remains later phase140. Retrieval opportunities use strictly later
   instants and an equivalent explicit cue/carry join if feedback is enabled there.

The symbolic declaration packet must specify whether the scene-side parent for the
join is allocation preparation or completed selection. Spatial pool modulation must
precede allocation and selection if it is intended to affect selection eligibility;
if it only changes encoding allocation, that narrower claim must be explicit. The
current proposal changes continuous encoding allocation, leaving role eligibility/K
unchanged. It must not be labelled a passed capacity-narrowing phenomenon.

## Join closure requirements

The trusted adapter records exact producing event IDs and canonical parent outputs.
Both parents must target the same committed receiving instant. Required PRJ resolves
the scene ObserverId to the actual qualified CharacterId and compares it to the carry
subject before releasing the response. The character transformer receives the narrow
response, selected data and fixed calibration only. Every emitted child names the
actual parent association; the second parent cannot be hidden in a generic cache.

An unmatched, duplicated, foreign-run or stale carry rejects. Baseline profiles
generate an explicit disabled/no-feedback branch with the same declared graph, rather
than opportunistically checking whether a hidden cache has data. A forged public
carry is not an original-input alternative. Absence of an expected parent is a failed
join, distinct from a successfully delivered Unavailable response.

Rollback restores both pending parent associations and all instant-local consumption
state. Saves occur only at successful whole-instant prefixes: before receipt the
pending queue contains the exact carry; after successful receipt there is no dangling
half-join. Restore reconstructs associations from authenticated original-prefix replay
and exact queue equality, not serialized private WeakMap handles.

## Review disposition

The join is necessary, but its complete registration/output schema and finite work
bounds remain open. A scalar q passed to a callback, an extra arbitrary phase, or an
unlogged private carry cache would not satisfy this refinement. No affected public
implementation may proceed until the whole packet closes these details. This is a
design requirement to resolve autonomously, not a request for a new user decision.
