# Outcome attribution: first contract decomposition

2026-09-12. **DRAFT, not whole-shape accepted.** Implements no public transition and
proposes no permanent number. Consumes the [accepted credit ruling](GENERAL_ATTENTION_CONSOLIDATION_CREDIT_RESOLUTION.md).

## Minimum semantic result

Keep three questions separate:

| Question | Owning operation | What a positive result licenses |
|---|---|---|
| Is this encoded episode supported as connected to this experienced outcome? | OutcomeAttributionAssessment | Eligibility for this causal-credit path |
| What effect is supported by the permitted evidence? | Separately specified effect assessment | Only the measurement/estimate meaning its contract proves |
| What changes in memory follow? | Consolidation assessment and registered mutation owner | Only the accepted memory update |

Attribution must not manufacture the operands for the other two questions. In
particular Supported does not mean exact effect, positive benefit, correct prediction,
reward, success, factual causal certainty or a guaranteed nonzero memory change.

The thinnest proposed first result domain is Supported / Unavailable. Unavailable
has no magnitude, confidence or Boolean causal judgment. Supported has no numeric
effect or invented confidence. A future contrary-attribution state is not mapped to
either zero effect or a retroactive deletion; its law remains separate.

This two-state candidate does not deny uncertainty in the architecture. It merely
avoids claiming calibrated degrees before a source and numerical rule exist.

its existing selection occurrence. A bare occurrence, archive record or caller-
supplied valid-looking retained encoding cannot mint the capability. Retained
content excludes unencoded units; linking by selection does not permit reading
the original full selected envelope.

Consume the accepted consequence227 →269 →270 path unchanged. Numeric observation

broaden CharacterEvidenceRef or copy truth dispatch ancestry into cognitive input.

Same-instant targets require a separately admitted positive-retention proposal with
the exact selection address; the barrier validates its corresponding base formation
and consumes it once. This is an explicit composition input, not a memory read of
an uncommitted sibling. Later-instant targets require the actual committed episode.

## First source investigation: observable interaction, not a causal label

Investigate a bounded interaction source whose raw features describe observable
motion/contact and a device's visible response. The character rule may interpret
that interaction together with an experienced outcome as support for a connection.
It must be possible for the device's response and bodily change to have independent
hidden causes. The source may never emit “caused relief,” “effective,” “creditable,”
an episode address selected by hidden provenance, or an authored per-object weight.

This is an investigation proposal, not an accepted attribution law. In particular,
an observed device response is not automatically evidence of its connection to a
body change. The next source review must state the exact fallible inferential rule
and what observable feature beyond temporal proximity supports its conclusion.
If that rule needs prior knowledge, inspect and contract that prior separately;
do not impose a belief store by naming the assessment or relabel diagnostic-level
prediction as causal knowledge.

The experiment must hold acquired episode, permitted outcome, time and body evidence
fixed while varying only permitted interaction/connection evidence. A second pair
holds all admitted evidence fixed while changing hidden causal truth. The former
must distinguish supported from unavailable under the candidate rule; the latter
must preserve the assessment, including when it is objectively wrong.

Physical truth generation, sensory permission and character inference must each
have separately testable outputs. Existing glyph continuity can connect perceived
continuants across views but cannot by itself prove event-to-outcome causality.
Exact observable features, feature-source lifecycle, observer-safe event pairing,
record shapes and the inference rule are still missing. No canonical source is
implemented until those are whole-shape reviewed and allocated separately.

## Adversarial review of this decomposition

The accepted ruling corrects a potential overconstraint in the decision discussion:
explicit attribution does not require an explicit causal belief. This draft therefore
adds no belief read, belief write or same-event belief order, and does not decide
ORD-001. The suggested interaction experiment remains a hypothesis subject to the
source review above, not a manufactured positive witness.

The earlier body counterexamples remain valid even after Supported attribution:
two equal safe bin pairs can hide Applied10 versus1. Neither source authentication
nor a Supported tag can turn those equal inputs into different hidden-effect values.
Outcome magnitude/surprise and the update law remain separate work. The former32
draft attention recipes have neither this source nor these assessment stages; their
registrations, model commitments and work estimates cannot be reused as closure.

Next: inspect existing permitted feature carriers and physical producer conventions,
then specify a falsifiable interaction-to-attribution rule with an inhabited
supported-wrong case. No weakening of the source gate, general attention completion
or corpus promotion is proposed.
