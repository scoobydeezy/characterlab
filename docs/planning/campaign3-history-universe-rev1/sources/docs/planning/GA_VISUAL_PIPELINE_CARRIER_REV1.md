event detection, with zero to three observed feature detections. Position and glyph
are independently optional; neither implies a role. EventRoleEvidence is the existing
observer-safe role sum, including unresolved. The public producer must authenticate

detections do not imply no experience: another actually sampled channel can justify
the shared reservation. The context companion requires its actual panel observation

selection. AvailableFile requires an actual current detection, its current SEM track,
frozen experience and supporting observation. UnavailableCue has no file/detection.
The first profile has one current cue detection. A broader ambiguous multi-detection
cue must reject this profile; it cannot pick an arbitrary remembered file.

The cue carries no coordinate, role, sample archive or content resolver. Event recall
uses the existing direct/graph decomposition and canonical acquisition ranking.
Cue admission causes no acquisition, presentation, use reinforcement or significance.

this inventory does not remove it or substitute bodily goal qualification for affect.
