# Attention encoding source design — revision 1

2026-09-11. DRAFT source contract investigation for the revised public inventory.
No source/profile shape acceptance, schema allocation or implementation authorization
is asserted by this draft. Old attention-public-integration/0.1-candidate is unchanged.

## Bounded observed scene

Use three governed discrete scene objects per original, with actual event-role
bindings and physical grid position/glyph facts. Reuse existing governed content
identities for those objects; they are never projected as character identity or
PerceptualReferentId. Positions are integer grid cells0..7 and glyphs categorical0..7.
A glyph is a visible physical mark; equality need not imply the same actual object.
Source originals may swap marks between objects, creating false tracking controls.
No original contains attention, salience, memory strength, Incidental, concern,
episode address, perceived file or relevance judgments.

A new exact profile declares detection permission and separate role/glyph/position
channel availability. A denied detection emits none of its features. An admitted
detection can still lack any particular feature. Known role is derived from the
actual world event binding through the same exact/unresolved semantics as the
qualified source. Known coordinate/glyph comes only from its corresponding admitted
physical readout. The truth object handle stays in the outer source and trace.
Changes to withheld features must preserve observer-side outputs exactly.

The proposed horizon is four possible formation sweeps followed by up to four cue
sweeps, strictly increasing in time. No more than eight marker sweeps or three
current detections per sweep are admitted. Existing OMT applies actual SEM NewTrack
or ContinuesPriorTrack transitions. Persist only the immediately prior permitted
glyph/file/observation matching window plus the existing actual SEM counters/files;
this is perception-owned state. A fresh public decoder must reconstruct that state
under an exact governed shape, not retain an uncheckpointed WeakMap across restores.
The graph can contain at most12 encoded files, even if later cue fragmentation makes
additional active perceptual files. Unknown cue files are not inserted into memory.

Event files are freshly allocated for each current scene event. Perceived continuant
files can persist by actual marker continuation. Event grouping remains SEM-owned;
no cross-event causal-role aggregation is introduced. Existing accepted binding,
experience staging and exact role derivation follow tracking. No new SEM appearance
feature or causal-role derivation is required by the spatial alternative.

## Selection and continuous allocation

Role eligibility/priority uses the existing Actor/Target/Participant evidence, with
the same missing/multiple/unsupported exclusion. K0..2 and unlimited/equal-priority
controls remain separate models. Independent continuous allocation candidates are:

1. Existing role calibration and disabled-attention control.
2. Positive spatial calibration under SCA: fixed rectangle, FocalWeight and ResidualPool.
   This does not create Incidental evidence or replace its historical control.

Spatial allocation is computed over all permitted detections before selection.
Selection then transfers only selected bindings/claims and, in the spatial model,
the selected units' allocation witnesses. Each witness binds the actual detection,
observed coordinate, spatial class, preselection peripheral count and calibration.
That count is an explicit observer-safe aggregate, not permission to read unselected
bindings or full observations. The consumer cannot recompute the denominator over
winners. Unknown selected position produces SpatialAllocationUnavailable and no
spatially weighted encoding row; it is not zero strength or a fallback role weight.
The disabled-spatial comparison must have a separate explicit policy.

This needs a successor selected envelope. Do not add fields to old534, broaden the
old capability's reader, or treat a caller-supplied spatial object as a trusted
companion. The new producer must authenticate allocation and selection outputs from
the same observer/detection/instant and enforce complete selected-only copying.

## Encoding and cue relation

The first homogeneous prior remains explicitly3/10, with no claimed category evidence.
Role R remains actual selected causal evidence; A comes from the named calibration.
Need/surprise Disabled is a restricted comparison, not full MEC-007 qualification.
Both UnitBudget1 and SmallBudget1/5 are proposed committed denominator controls; the
latter already has source-connected component witnesses that cross the shared branch.

Later cue detection uses the same physical glyph/permission source and actual SEM
tracker. Exactly one cue detection is designated by the closed source grammar, not
by a caller-provided memory key. If there is no admitted glyph/file match, preserve
UnavailableCue versus NoKnownAssociationMatch distinctly. Otherwise b is1 at the
current matched file and0 at other existing graph nodes, explicitly as a cue-query
calibration. Those zeros mean no activation injection from this cue, not evidence
that the other objects are absent or unknown. A beta0 local comparator retains the
same source and history and removes only associative propagation.

## Remaining shape obligations

The source needs its exact original schema, physical feature observation record,
tracking-window leaf, cue grammar, selected companion/view shape, roles, fixed
members, registrations and occurrence rules. The old phase/stage record541 cannot
be reused with altered fields or writes. Required PRJ attaches only after new actual
input admission; all persistent character writes and reads use the qualified owner.

Source review must execute hidden role/glyph/position changes, independent channel
missingness, glyph swaps, ambiguous glyphs, interrupted and replayed sweeps, exact
selected-witness attachment, denied detection, owner mismatch and ordinal renaming.
No source bytes are accepted until that complete symbolic packet is closed.

Historical Incidental/Cause, category variation, realized Need and evidence-aware
surprise still require explicit control/source dispositions. This draft does not
erase those requirements by naming the geometry model general attention. Future
attention verdicts must say exactly which of those source comparisons were executed.
