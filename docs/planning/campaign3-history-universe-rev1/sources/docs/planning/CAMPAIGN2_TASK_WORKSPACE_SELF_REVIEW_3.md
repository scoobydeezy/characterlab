# Preserve conflict before fixing workspace capacity

2026-09-09. Agent adversarial review3. **Whole shape remains withheld.**

## Remove an unnecessary restriction that would defeat the retained decision target

The timing review proposed nonoverlapping task windows for a holder/prediction
definition. That restriction is unnecessary for deadline safety: each concrete
task has a different key, and at its own deadline it is excluded from measurement
applicability by the half-open window. Different active tasks cannot collide merely
because their windows overlap. The restriction would also prevent the first model
from representing competing live commitments over the same known forecast.

Replace it with a finite first-profile bound of **at most two concrete tasks for
the one qualified holder and prediction criterion**. Windows may overlap. Each
measurement dispatch resolves0..2 distinct keys in canonical order, reads their
priors independently from B0, and emits an exact0..2-operation patch under the same
sole prospective authority. It does not aggregate the two tasks into one status.

Clock versus measurement targeting remains disjoint for each individual key:
T=Deadline cannot satisfy that task, while a distinct recurrence or competing task
may still be active. Source-event multiplicity remains separately constrained by
the new input/profile grammar; this is not permission for arbitrary duplicate342
dispatches. No same-target priority rule is introduced.

## A bounded workspace capable of retaining that conflict

Propose a capacity of at most three semantic items: up to two active task contexts
and one shared forecast. The forecast is one item/read even when both goals refer
to it; copying it into two independent causal facts would later inflate evidence.

Candidate selection rule, to formalize before acceptance:

1. IDN derives the qualified holder from the authenticated deliberation opportunity.
2. Read the finite0..2 declared task statuses, preserving actual absence/dormancy/
   terminal eligibility. Select active tasks by earliest Deadline, then complete
   canonical task-key order for exact ties. IDs break equal-order ties only; they
   supply no magnitude or priority score.
3. With capacity≥1, retain the first active task. If capacity≥2 and forecast access
   is enabled, read/retain the one owned prediction if present. If no prediction
   exists, retain explicit unknown-forecast status rather than a zero value.
4. With capacity≥3 retain the second active task, if one exists. Both refer to the
   same selected forecast/unknown result. No second prediction read or source basis
   is manufactured for the second goal.

This exact priority order is a laboratory candidate, not accepted general attention
or salience. Capacity controls must separately distinguish insufficient workspace,
absent prior and a read-access ablation. A trace may record why an operand was
unavailable; downstream psychology must not mistake unavailable for known neutral.

The first live cognitive target can now retain two incompatible desired intervals
and later produce two genuinely independent commitment base motives. It does not
yet claim those are Reason Nuclei, action efficacy beliefs or a completed contest.
The mandatory raw-signal/consolidation/dice pipeline remains downstream.

## Appraisal and affect direction

Appraisal produces a separate assessment per selected task using the shared forecast:
UnknownForecast, Below, Within or Above. Known discrepancy is exact distance to that
task's desired interval. Within is known zero discrepancy, not unknown. Neither
assessment retires the task; only the separately admitted actual observation can.

Propose a separately typed concern conclusion with exact dimensionless intensity
K*distance/10, where K is a governed **model calibration**, not task content and
not a belief confidence. K lies in[0,1], distance in[0,10]; no clipping is needed.
Unknown forecast produces unknown concern, not numeric0. The denominator10 is the
declared prediction-domain span, not REG's scale or a unit conversion.

Retain base obligation pressure as a distinct source computed only for an actually
selected live task. Concern must not become a second independent obligation or
command an action. Any influence on later reasons needs the explicit modifier and
shared-evidence contracts; it cannot be counted twice because it has a new record ID.

## Review conditions still open

The final workspace record grammar must distinguish unknown context, no active task,
selected tasks and forecast availability, without exposing policy instrumentation
as spurious character knowledge. Exact source/output identities, child scheduling,
read/write domains, numerical profile and ablations still require a complete seam.

The task content kind, prospective route and combined140 registrations also remain
unaccepted as a whole. These proposed corrections precede permanent allocation and
implementation. Existing prediction and earlier Campaign2 verdicts are unchanged.
