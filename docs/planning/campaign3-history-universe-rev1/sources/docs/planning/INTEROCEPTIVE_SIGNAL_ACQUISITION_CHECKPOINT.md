## Implemented component

`interoceptive-signal-selection-component/0.1-candidate` groups actual-shaped EMB
samples solely through a supplied channel→signal declaration for one explicit
opportunity. Equal-priority selection counts groups, not views. Every selected present
sample survives exactly; contradicting readouts are not fused or ranked by precision.
The detached one-use view has no discarded-sample archive or arbitrary payload lookup.

Separate finite parameters bound signals, views, selected groups and retained bytes.
The tests'3/3/4096/2 values are component specimens, not accepted public calibration.
The earlier sample-level source and qualification remain unchanged as a comparator.

[Eight component tests pass](INTEROCEPTIVE_SIGNAL_SELECTION_TESTS_REV2.json).
Revision1 preserves the earlier run; revision2 adds the explicit P-with-three-views
plus Q witness, showing that P consumes one slot and does not displace Q at capacity2.
[Seven source substitutions are detected](INTEROCEPTIVE_SIGNAL_SELECTION_REVIEW_REV1.json):
view-count charging, opportunity-from-time, dropped conflicting views, ignored byte
bound, reusable capability, duplicate observations and selection of an absent signal.

These tests authenticate neither the supplied signal declarations nor a physiological
source. Giving three component symbols different names does not prove three experienced
signals in a public model. Public source diversity remains an explicit gate.

## Opportunity identity reuse

The substrate has no need for a duplicate acquisition-opportunity namespace merely
to express the new gate. `ExperienceId/1106` already identifies a reserved, immutable
observer-side sensing envelope. For a future nonempty multi-view opportunity, propose
one actual frozen227 whose support set exactly covers the admitted present samples;
the gate's opportunity key is that existing ExperienceId. The dedicated adapter must
bind it to the live source, exact samples, observer, instant and declarations.

SO-A..C execute actual SEM reservation/freeze/settlement components. Two opportunities
at the same time and observer receive distinct IDs and pass settlement. Multiple
observations can support one envelope with one allocation. An opportunity with no
character-accessible evidence reserves no ExperienceId. Thus absence must not mint
a fake experience simply to supply a memory key; an all-unavailable source has no
durable candidate, with original-event accounting remaining trace-side.

The signal component's structural bigint opportunity is only a component parameter.
The proposed public carrier uses typed1106, not a naked scheduler event ID or an
omniscient event handle. This is a forward public-design refinement, not an allocation
or retroactive change to the component's tested input domain.

[Combined report](INTEROCEPTIVE_SIGNAL_INTEGRATION_TESTS_REV1.json):27 tests pass
(8 grouped gate,7 preserved sample gate,9 preserved attribution,3 SEM identity).
They do not qualify public multi-view SEM support matching, source admission or restore.

## Next public source gate

Current public EMB has one reserve-level signal. Three channels or resolutions of
that signal cannot provide the required three-signal contention experiment under
the accepted unit ruling. A genuinely multi-signal source requires an explicit
physiological/sensory model, not more labels in a grouping table.

The [prepared source proposal and architectural choice](GENERAL_ATTENTION_MULTISIGNAL_BODY_SOURCE_DECISION.md)
compare a bounded three-local-reserve body with multiple distinct sensory responses
to the existing single reserve. The former reuses accepted analytical operators but
extends the physical state domain; the latter preserves physical state but needs
new sensation/transduction semantics. Neither is implied by selecting signal-level
capacity. No public body source or durable carrier has been implemented while this
choice remains open.

Proposed durable direction remains a peer episodic acquisition with qualified
CharacterId ownership and a bounded exact sample basis keyed by opportunity/signal.
It must participate in ordinary declared memory reads/retention, not an unselected
sidecar. Its exact records and writes await source closure, whole symbolic acceptance,
separate allocation, model packaging and public proof. EVID269/270, old visual selection,
REG, old body/pressure profiles and corpus0.27.0 remain unchanged.
