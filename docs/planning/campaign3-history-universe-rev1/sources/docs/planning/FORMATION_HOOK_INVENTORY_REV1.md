variant values, not new identity families. Source binding names the exact admitted
producer/output schema/version and required PRJ descriptor. Result binding names the
actual ordinary-owner validated batch result, never a arbitrary callback or matching

authorized writer from deleting enrollment or resetting prior success: generic
