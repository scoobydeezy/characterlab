# First survival-priority evidence basis

2026-09-12. **DECISION REQUIRED.** Cost, complete-unit loss, per-kind partitions
and ordinary-memory authority remain accepted. This choice concerns the causal inputs
to survival priority, not those previously settled decisions.

## Available evidence

Acquisition time is available. Semantic child identity supplies deterministic addressing,
not importance. Visual encoding factors/strength have no accepted retention meaning.
Body groups have exact sample bases but no strength or importance field. View count,
interval width, pressure and physical reserve identity cannot fill that gap.

MEC-010 supplies presentation-history semantics for accessibility. A completed authorized
presentation is distinguishable from a cue, rank or failed retrieval. Using presentation
history for survival would still introduce a new edge: retrieval/use → retention
reinforcement. The per-kind ruling allows investigation of such a separately qualified
hypothesis; it does not already accept that edge.

Supported attribution is causal-credit eligibility, not effect magnitude, benefit,
importance or protection. TaskConcern is not Need. Neither is a substitute retention
operand. Current accessibility remains excluded from the first eviction policy.

## Concrete alternatives

**A — age-only baseline first (recommended for the next bounded control).** At an
explicit retention barrier, keep the most recently acquired units within each kind,
with a declared canonical tie rule. Age uses actual acquisition time, not occurrence
magnitude, and retrieval does not reset it. This uses an existing operand without
claiming acquired importance. Exact tie handling, newly formed units, zero capacity
and batch timing must be frozen before implementation.

A can demonstrate partial survival and genuine loss. It cannot explain a defining
old memory outliving newer routine content. That remains an unmet North Star
obligation: A must not be used to close General Attention with an age-only memory
model or defer acquired importance indefinitely. Preserve it as a comparator for
the later protection/reinforcement candidate.

**B — retention-specific reinforcement now.** Authorize the new causal edge from
completed admitted presentation/use history to a separately specified retention
state or priority. Cue activation, accessibility score, being ranked and failed
retrieval do not reinforce. The law must distinguish acquired survival benefit from
current retrievability and preserve initial encoding bytes. Unit-versus-acquisition
credit, one-use producer binding and prevention of self-sustaining recall loops need
exact contracts; merely counting presentations as an eviction score is insufficient.

B is viable but not forced by available metadata. It also does not by itself explain
important never-retrieved memory. Outcome-dependent importance still requires its
own independently justified assessment. Neither option creates a cross-kind scale.

## Why this is a decision

Holding admitted units and capacity fixed, A can lose an older frequently presented
unit while B may preserve it. The difference is a psychological feedback path, not
a data-structure choice. Conversely, calling age-only survival acquired importance
would erase a required phenomenon. Recommendation: build A as a named bounded
baseline, then the independently specified acquired-protection candidate. Age is not
recommended as the final retention model.
