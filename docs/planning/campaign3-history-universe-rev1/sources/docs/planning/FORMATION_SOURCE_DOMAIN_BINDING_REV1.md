# Finite source-domain binding: successor proposal

2026-09-12. PARTIAL PUBLIC PROTOCOL DRAFT; NOT ALLOCATION INPUT.

## Substrate findings

Selection and acquisition identities are runtime occurrences. The existing phase130
formation proposal authenticates completed selected encoding and emits acquisition
evidence only for nonempty positive content. Its empty branch emits no formation work.
Binding a public run to a preauthored list of future opaque selection IDs would therefore
need an additional derivation/reservation rule that has not been accepted.

The bounded history ruling permits a finite distinct admitted source domain. Track that
domain separately from successful rows as actual qualified sources reach the boundary.
This extends the pure history component's supplied universe; it does not add failed-
attempt outcomes. A domain member can have no successful governance row.

## Proposed boundary

1. Authenticate actual completed selection/encoding origin and exact observer/time;
   consume required accepted PRJ/IDN to obtain the qualified subject. A copied source
   ID or caller-supplied CharacterId is insufficient.
2. Construct the exact distinct qualified formation-source set for the admitted batch.
   Check its union with committed run-domain metadata against fixed lifetime N.
3. Only admitted sources proceed to formation eligibility. Empty/zero content produces
   no acquisition occurrence or success row, but does not erase admitted membership.
4. Positive evidence follows the already proposed phase130→140 path. Successful history
   and content/loss dispositions commit under the existing whole-instant boundary.

The protocol-domain check cannot be hidden solely in the successful phase140 writer:
that would leave never-successful sources unbounded. Conversely, adding protocol
metadata must not silently grant character-family writes to the write-free producer.
Exact integration with runtime admission and persistence needs a complete public
declaration. This draft does not assign a new authority or allocate a root.

## Run binding and save/restore obligations

Bind the lifetime N in immutable run/profile configuration and retain the exact admitted
source set plus successful governance rows in the accepted continuation package.
Restored domain must include every successful source; subjects/kinds agree; acquisition
IDs remain unique; live target/disposition correspondence is checked; the existing
runtime allocator remains authoritative for nonreuse. No load-time reset, narrowing,
oldest-row deletion or changed-N continuation is allowed within the same run.

The metadata contains no forgotten children or resolver. A source can be admitted again
without a new domain slot, but if it already formed, the success table rejects a second
initial acquisition. New source N+1 rejects at admission, not as a cognitive event.
The proposal does not add an end-of-run notification or public gameplay behavior.

## Executed component evidence and remaining gates

[Fourteen combined tests](FORMATION_SOURCE_DOMAIN_TESTS_REV1.json) pass, including
six source-domain cases: never-successful saturation; already-admitted replay distinction;
loss/continuation preserving capacity; subject/kind qualification; atomic set extension
and canonical ordering; zero/invalid bounds and duplicate declarations. Eight earlier
governance cases remain passing. StructuredClone checks are not canonical persistence.

Public typed source address, domain/history owner placement, exact fields and lifecycle
presence, no-positive-output admission hook, full source/role/output/work inventory,
numeric allocation, canonical codecs and committed model packaging remain gates.
The current symbolic documents are partial; no public source-domain implementation
or General Attention completion is claimed.
