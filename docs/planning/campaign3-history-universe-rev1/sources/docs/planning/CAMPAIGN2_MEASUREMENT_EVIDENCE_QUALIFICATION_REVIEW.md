## Implemented behavior

The data-only factory admits exactly the frozen positive model and its four committed boolean
variants. Production declaration construction reproduces the frozen positive ModelIdentity;
no stored packet is used as a construction input. It selects the unchanged probe ordered-input
profile and the new registry, trace and persistence behavior directly from the frozen RulesVersion.

The V07 registration is admitted alongside unchanged V04/V06 rows. Its new input/output
occurrence rules use the existing shared occurrence interpreter with the new committed schema
and role declarations. There is no second provenance or observation-identity system. Generic
V04/V06 decoding retains its prior schema set and semantics. The first V07 profile remains exact,
not an open registration language or a universal V04/V06 superset.

Actual permitted phase-120 diagnostic 203 production is validated at the fixed observer-side
adapter, then reported to shared ingress. Shared ingress discovers the committed consumer and
owns the allocated intake child. The probe owns only tracking. Suppression produces only private
profile padding; missing/duplicate matching consumers cannot be repaired with padding.

The detached semantic consumer receives exactly observation, safe unit and allocated occurrence.
It publishes one 337 containing the exact 203 and unit; no state/model/trace/REG resolver is an
operand. Shared completion verifies the execution-allocated identity and exact admitted source.
No persistent state family is read or written by intake; no learning-route mapping is added.
Six runtime advances and eight generated children are checked before commit for every probe
branch. Phase-120 trace closes both children under successor ownership; padding is not V07.

Restore validates historical 337, the exact corresponding source/child/trace chain, unit/observer/
version, occurrence rule, allocator bound and the accepted observation-to-carriage ordinal spacing.
It never recomputes historical measurement from current R0/D or permission. Save wire fields and
empty analytical/random/continuing-input metadata remain unchanged.

## Retained defects and corrections

The first focused runtime pass produced correct intake/padding but restore omitted the carriage
configuration when reconstructing the runtime, selecting the old probe trace binding. Restore now
passes the compiled carriage configuration explicitly; all four branch save/restore controls pass.
This was an implementation defect, not a contract or frozen-byte change.

The first full parallel test run had four existing five-second timeouts under contention. The
focused probe run passed; the complete suite then passed with two workers and unchanged timeout
settings. The initial sandboxed Vite invocation encountered the known esbuild config-access limit;
normal-access execution succeeded. These environment failures are not counted as semantic passes.
