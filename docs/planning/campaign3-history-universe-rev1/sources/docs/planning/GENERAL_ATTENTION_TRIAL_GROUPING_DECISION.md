## A — explicitly perceived bounded trial context (recommended first source)

Give the first controlled source an observer-accessible trial boundary/context, such
as a perceived start/end cue whose admitted event/context identity links observations
under a declared finite protocol. It states which evidence belongs to the observed
episode, not that the candidate caused its consequence. Actual sensing, source
admission and retained context must establish the link; caller labels do not.

Use that experienced context for before/motion/after pairing and the pre-verdict focal
hypothesis. Contrastive attribution still supplies the causal inference and can be
wrong when a hidden independent input produces the same observations. The cue must
not encode stroke/control classification, hidden reserve/delivery identity, successful
effect or desired target address. Exact cue semantics/identity must be contracted;
do not assume opaque IDs are character-readable meaning.

This bounds the first phenomenon to an explicitly structured observed episode. It
does not establish ordinary unguided event segmentation or general causal attribution.

## B — observer-side temporal/event segmentation first

Infer trial membership through a separately versioned bounded segmentation process
over actual observed event boundaries, timing and attention. It must decide how
overlap, delay, interruptions and ambiguous pairing behave without hidden source
labels. This supports less structured experience but requires a new grouping law.
Temporal proximity can define a candidate grouping under that law; it still cannot
by itself produce Supported causal credit.

## Decision and controls

Recommend A for the first controlled source, retaining B as the broader segmentation
candidate. Distinguish lost/unobserved context, swapped context identities, observation
outside its permitted window, foreign observer, and changed hidden truth with identical
observed context. No grouping should be inferred from array order or a source-only
trial ordinal. These are proposed source controls, not passed public vectors.
