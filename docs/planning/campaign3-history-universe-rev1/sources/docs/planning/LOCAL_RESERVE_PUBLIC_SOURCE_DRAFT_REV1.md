are fixed fixture members in different namespaces; neither array position nor text

## Source definitions and safe projection

LocalReserveDefinition carries physical identity, capacity and depletion rate. A
channel definition carries physical source, safe signal identity, width, permission
and availability. In this fixture exactly three safe signals are bijectively mapped
to the physical reserves, with bounded multiple views per signal. This mapping is
source behavior, not a general physiological identity law.

The source-only definition may contain physical keys. The gate receives only the
safe channel→signal projection and actual sample outputs. Neither physical keys,
state accessors, model registry objects nor permitted/available cause flags cross
that boundary. Absent and denied views have the same character-visible unavailable
shape. Equal values do not merge signals; hidden key renaming with the same safe
mapping must leave observer outputs unchanged.

Use the existing exact reserve operators. The public successor must have its own
source seam/profile version and declaration closure. Existing461/462 interval layouts
may be reused only with explicit schema/producer admission; do not claim that a
multi-reserve sample was produced by the old singleton body factory. New signal
identity context is a separately governed companion, not an extra field silently
added to461 or a broadening of CharacterEvidenceRef.

## Selected acquisition and ordinary durable memory

The public gate consumes the exact live opportunity, safe declaration and samples,
then runs signal grouping/selection. Its transient full input never becomes a memory
archive. The selected result contains only positive signal groups and their bounded
present sample bases, along with observer, actual experience identity and selection
provenance. No pressure, salience multiplier or integrated estimate is created.

Propose a peer episodic retained acquisition rather than inventing a body continuant
inside the visual unit domain. Its durable identity must reuse the selected acquisition's
existing occurrence address where semantically admissible; the SelectionOccurrenceId
family1143 is a reuse candidate requiring explicit public role/output review, not a
new allocation or presumed permission. A group inside the acquisition is addressed
by its safe signal identity. No redundant MemoryEpisodeId is proposed.

Its formation writer, ordinary memory read domain, cue/lookup rule, finite retention
and presentation history must be first-class and governed. Merely naming a separate
root episodic does not satisfy the prohibition on a hidden sidecar. Downstream
attribution may read only selected retained groups through this memory contract.
It cannot recover a lost signal from pressure, trace or the source's original stream.

Multiple acquisitions in one instant must reconcile under one declared family
authority and common-B0 barrier composition. Independent patches replacing the same
character leaf would lose an acquisition and are forbidden. The exact batch shape,
owner preflight, ordered append law and per-instant work/output bounds still need
whole-shape review. Lifecycle B preserves initial bytes, even when a consequence is
also sensed in that instant.
