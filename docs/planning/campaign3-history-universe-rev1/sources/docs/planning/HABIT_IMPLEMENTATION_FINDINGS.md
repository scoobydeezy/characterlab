# HABIT implementation findings — 2026-09-21

HABIT-IMPL-001: initial TypeScript validation caught an un-narrowed arbitration mode,
a readonly draw-list assignment and a missing record-type argument in trace source
extraction. These were corrected before public execution. The first experiment
evaluator also had an extra parenthesis; it failed parsing before any run and was
corrected without altering its frozen input plan or any model/contract byte.

HABIT-FIND-001: the canonical route exercised here is Habit → Candidate Option
Construction. Acquired history changes candidate availability, not a motivational
weight added directly to arbitration. Once reward expectation is corrected to neutral,
the retrieved action and idle alternative can tie under the inherited exact choice
grammar. This is a bounded persistence witness, not stronger preference or compulsion.
Any later claim of resistance to deliberate counter-reasons needs an additional test.

HABIT-FIND-002: derived journal folds and stored summaries are explicit competitors.
Their cross-leaf equality is enforced at committed instant boundaries: a history append
temporarily precedes the cache refresh within one transaction. No observer or later
appraisal may see this intermediate state. Fault injection after each stage, including
the history append, must restore both representations and addressed-random state.

The journal is a profile-local safe evidence history. Equivalence with its own fold
does not establish equivalence with episodic recall, association, identity or skill,
nor does it justify deleting those architecture distinctions.
