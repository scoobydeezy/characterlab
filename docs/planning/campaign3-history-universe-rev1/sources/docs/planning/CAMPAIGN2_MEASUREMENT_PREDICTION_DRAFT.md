## Totality, typed failures, instant rollback, and failed-run behavior

No numerical overflow or machine wrapping: arbitrary-precision exact arithmetic.
Failures must use a committed typed owner, not a Boolean no-op. Existing substrate

PredictionSourceMismatch, PredictionObservationAlreadyApplied,

trace and marks Failed. A retained invalid leaf cannot be repaired by new evidence.
An invalid candidate must not be clipped into the domain.

## Exact transformation

Let x be the admitted203 point (equal interval endpoints); b its existing
CharacterEvidenceRef observation identity. If prior absent, next=(x,{b}). Otherwise:

    n = cardinality(prior.EvidenceBasis)
    next.ExpectedReading = (n*prior.ExpectedReading + x)/(n+1)
    next.EvidenceBasis = prior.EvidenceBasis union {b}

This is exact equal nominal weight, not precision estimation. 203's precision=1 is
a source-admission constraint and never a formula operand. Source time is preserved
in its existing source record; there is no decay or timestamp-based learning rate.
The formula is permutation invariant for distinct points with unchanged membership;
proof is the independent sum/count oracle, not sorting IDs before an order-sensitive
update. Cardinality is not interpreted as independent evidence or certainty.
