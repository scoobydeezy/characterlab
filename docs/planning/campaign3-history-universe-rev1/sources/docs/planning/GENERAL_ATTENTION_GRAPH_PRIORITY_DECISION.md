## Available operands and authority

The current learned graph provides semantic endpoints and exact directed weights.
Its graph-wide update timestamp is not an edge-specific learning date. No edge-local
age, completed-use history, familiarity or importance field is accepted. EAM weakening
changes weights under its exact mathematics; that alone does not authorize weight
as a scarcity priority. MEC-008/009 remain learning/access controls, not forgetting laws.

Canonical semantic addresses establish deterministic ties, not psychological worth.
Current activation cannot be borrowed as survival authority. Episodic retention age
and presentation history belong to distinct state and cannot silently migrate here.

## Concrete alternatives

**A — weakest-weight-first as a named bounded control (recommended first).** Explicitly
authorize existing exact positive edge weight as the first scarcity ordering: ascending
weight is lost first, with canonical directed-address ties. Apply that complete ordering
to the resolved batch until both capacities hold, then normalize once. Node pressure
may require a prefix containing several edges. Neither endpoint degree nor a search for
the fewest deletions changes the ordering. An empty graph makes every valid capacity
pair feasible. This proposal adds no edge-local retention field.

This is a deliberate strength-to-survival hypothesis, not a consequence of unit cost
or an importance theory. It can lose a weak but behaviorally useful bridge before a
strong redundant relation, and may delete several weak edges before freeing a node.
Those consequences must remain explicit counterexamples/comparator targets. Do not
claim optimal retained influence or minimum loss. New edges receive no hidden grace
period. Equal-weight canonical ties remain mechanical controls.

**B — separate edge learning-recency baseline first.** Add an independently governed
last-lawful-learning time per directed edge and lose least-recently learned relations
first. This distinguishes survival age from strength, but requires a new retention
state surface and exact refresh rules: positive contribution versus net quantized change,
decay-only updates, repeated same-barrier evidence and loss/relearning. Retrieval or cue
activation cannot refresh that time without another authorized feedback path. The
existing graph-wide timestamp cannot stand in for it.

## Distinguishing prediction and proof burden

With edge capacity one and room for both endpoints, let a→b have weight .8 and older
learning time, and b→a have weight .1 and newer learning time. A retains a→b; B retains
b→a. Their directed spreading differs. Both edges still cost exactly one slot. This
is a proposed operand example, not an executed B implementation or historical fixture.

For A, freeze exact comparison/ties and complete-prefix stopping; prove both independent
pressure modes, coordinated node release, zero budgets, smallest lattice weights,
weight/slot separation, input permutation and no survivor reweighting. Keep explicit
edge-plan validation separate from priority construction. Public batch/owner/rollback
and persistence remain additional gates. A slot bound must cause actual loss, not turn
a lawful public update into a rejected run.

For B, first close metadata ownership and refresh semantics before allocation or code.
Neither choice closes broader acquired protection or General Attention by itself.
The mandatory episodic reinforcement comparison remains separate and outstanding.
