# Task motive and procedural option bridge — research disposition

2026-09-09. Agent research direction, not an accepted contract or implementation.

## Keep the efficacy gap visible

MeasurementPrediction predicts a reading without conditioning on an action. Neither
task content, appraisal nor a true world-effect definition may supply the missing
belief that a particular action will achieve the desired interval. Option generation
must therefore name a different legitimate source or add an actual efficacy-learning
seam. A hidden table of "best action for this interval" in the option handler is
rejected even if it would make a convenient demonstration.

Architecture11 explicitly permits an active strategy/plan in prospective state and
bounded candidate strategies. For the first thin event, pursue the narrower candidate:
an initially adopted procedural instruction, meaning **what to try for this task**.
It is not a chosen current intent, guaranteed success or probabilistic effect claim.
The character must still generate options, motives/reasons, arbitrate and form a new
intent; an initial plan cannot be submitted as a hand-authored Reason or Decision.

## Representation boundary still needing symbolic closure

An authored procedure definition may specify an ActionDefinitionId and its semantic
arguments. Authored availability does not imply the character adopts or knows it.
Initial prospective plan state must explicitly bind a task key to an adopted procedure
reference, with absence meaning no adopted plan. No inferred mapping from interval
sign, task ID spelling, registry row order or world-effect magnitude is allowed.

Do not insert this new state silently into TaskCommitmentStatus. The current lifecycle
candidate's finite status and exact writes are independent of plan content. Review
either an explicit second prospective root under declared ownership or a separately
versioned value extension before allocating it. The plan binding must remain unchanged
when lifecycle status is replaced, and cannot resurrect a terminal task.

The first model may keep the plan binding immutable after S0. This is initial context,
not a claim of runtime plan acquisition or learning. A later plan revision requires
its own actual producer and authority. No character belief/appraisal/identity is
authored inside the procedure's content definition.

## Generated motive context before options

At60, the actual TaskConcern chain provides the selected active tasks. A separate
model calibration supplies one common positive raw obligation pressure P, which is
independent of forecast agreement and concern. Each selected live task gets its own
task-referent motive operand. A known in-range forecast does not remove that pressure:
the obligation persists until actual permitted satisfaction or expiry. Unknown forecast
does not manufacture a negative motive. No selected live task means no base operand.

Concern is retained as a separately sourced optional contextual contribution, not
added to P. The source-to-reason contract will assign it a non-generating role and
exact conversion. Standing identity remains another distinct modifier. The retained
compiler bounds role consolidation before activation; no upstream source should
pre-apply that bound merely to make its numbers match a desired die threshold.

## Generated procedural candidates at70

After authenticating the live motive-context output, resolve only adopted plan
bindings for its actual selected task keys. A missing binding yields no candidate
for that task; it does not fall back to a world-effect lookup. Proposed first-profile
procedures describe always-attemptable protocol actions, so content can determine
the action's structural availability while actual execution interference stays
independent and hidden until permitted consequences. "Attemptable" is not "succeeds."

An option carries its actual procedure/task origin. If more than one task proposes
the same complete action/argument tuple, either preserve a single option with all
its distinct originating tasks or reject that model under a declared first-profile
uniqueness rule. Do not accidentally duplicate the action into two lottery tickets.
This exact rule must close before shape acceptance.

No preference is used to decide availability, and no world feasibility test pretends
to know the later interference state. MEC-011 requires those distinctions to remain
independently intervenable. Plan-access and option-construction ablations must retain
the causal absence rather than inject an arbitrary default choice.

## Reason source/provenance obligations

At80, the task's base source targets the option generated by its actual adopted
procedure, with Commitment channel and concrete task referent. This reuses the
historical fulfillingAction control's attribution idea while making the procedural
source explicit and refusing an efficacy claim. It does not label the eventual
action successful or the social obligation fulfilled.

Concern must attach to that same concrete reason context as a modifier. Its sensory
basis is the existing prediction support observations, not the new concern occurrence
as an independent observation. Two downstream descriptions of the same forecast
must overlap completely when they use the same support. Do not normalize or invent
confidence weights merely because the forecast is a mean. TRC-004 owns the exact
typed aggregate basis and collective-redundancy rule before this adapter is accepted.

The base obligation is initial adopted context, not an observation. Its actual
state-read and procedure provenance must be traced; an empty observational basis
does not mean the compiler may duplicate the same generating fact. Source admission
must guarantee one base source per concrete task/option. Later identity evidence
has its own qualified expression basis; no synthetic tag may hide that provenance.

## Frozen research alternatives and exclusions

Compare adopted-plan absent/present, two distinct procedures and identical-action
deduplication, goal live/retired, unknown/known forecast, concern/identity ablations,
world interference with identical intent, and the historical active-list control.
The identity activation exploration supplies only a possible downstream boundary,
not generated motives, adopted plans or qualified identity evidence.

Deferred: learned action efficacy, general planner, dynamic adoption, plan revision,
skill-conditioned success, social fulfillment and explanatory causal attribution.
These are not needed merely to explain a procedural attempt, but a later phenomenon
requiring them cannot be qualified by renaming the procedure an expectation.
