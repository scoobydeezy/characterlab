# Direct signal / acquisition-recency body recall: A accepted

2026-09-12. **ACCEPTED by supplied planning ruling.** Resolves the body recall law
decision. Actual lawful current signal matching determines binary acquisition eligibility;
original acquisition time determines within-body ranking. Multiple matching signals,
views or retained groups supply no extra priority. Canonical IDs resolve exact ties only.

Original time never refreshes through recall, presentation, consolidation, fragmentation
or survival. Recall-recency is independently versioned from retention-recency despite
sharing that operand. The public experiment must retain older matching acquisitions
that lose recall slots, avoiding a survivorship tautology.

Absent/denied/unavailable current evidence creates no cue. Numeric zero is evidence,
not epistemic absence. Retained content, source IDs and trace cannot self-cue. The
successful target is the acquisition: a cue for alpha may expose still-retained beta
from that same acquisition, without asserting beta is present now. Group-local recall
is a separate future hypothesis, not the first profile.

Preserve presentation-history accessibility as the next serious body-recall comparator
requiring authenticated use, seed semantics, bounded history and anti-bootstrap rules.
Accessibility reinforcement is distinct from acquired retention protection; neither
qualifies the other. General Attention remains OPEN.
