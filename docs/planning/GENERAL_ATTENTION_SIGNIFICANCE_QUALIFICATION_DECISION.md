# Which goal-relative changes qualify for significance?

2026-09-13. Historical packet; [A subsequently accepted](GENERAL_ATTENTION_SIGNIFICANCE_QUALIFICATION_RESOLUTION.md).
Concern source and descriptive relation are accepted.
Their arithmetic does not determine whether an outcome matters enough to earn a
consolidation effect. This decision proposes the first bounded qualification law;
it is not an importance score or retention priority.

## A — both determinate directions qualify (recommended first)

Propose a binary outcome-significance candidate: a lawful MovingCloser or MovingFarther
assessment qualifies, preserving the direction as provenance. Both goal progress and
goal deterioration may matter. Neither implies correct objective attribution or
successful behavior. Do not turn a distance delta into a score, rank changes by
magnitude, or add counts. Supported attribution remains a separate target-credit gate.

This is an intentionally coarse hypothesis. Even a small determinate change qualifies;
repetition does not make the significance assessment quantitatively larger. Its
adequacy must be tested against stricter candidates, not assumed from the word
“concern.” Equal binary qualification does not declare equal emotional valence.

SameDistance is assessed but does not qualify under this candidate. IndeterminateRelation
and Unavailable remain distinct non-qualifying reasons, never assessed zero importance.
An equal-distance opposite-side crossing remains in the record even though A does
not qualify it. This limitation is explicit and may warrant a later positional law.

## B — goal deterioration first

Qualify MovingFarther only, preserving MovingCloser as a real assessment without
this consolidation effect. This is a concern-threat-biased hypothesis: adverse
movement gets durable priority but improvement alone does not. It needs evidence
for that asymmetry; the accepted distance formula does not imply it.

## Concrete discrimination

Use goal[6,8] with before5/after7 (MovingCloser) and before7/after9 (MovingFarther).
Both are positive observed signal changes, so the current positive-change attribution
candidate need not be broadened to a negative-change causal rule merely to compare
the two directions. Actual repeated trial/source authentication is still required.
Hold binary use protection, target age, retention budget and attribution support
equal. A qualifies both directions; B only the second. Preserve a separate change
that stays outside the goal so a boundary-only candidate cannot explain every result.

At this point neither candidate specifies target-child versus acquisition credit,
retained significance representation, saturation, competition with use protection,
or survival order. Those must be fixed in a composed contract before memory writes.
The proposal does not claim the old rarely-used-important-memory phenomenon has passed.

Requested ruling: authorize A as the first binary qualification hypothesis, or B if
the first concern effect should be explicitly deterioration-biased. Retain the other
as a named comparator. Public implementation and final retention composition remain gated.
