# Campaign 3 Decision and Escalation Policy

**Effective immediately.**

Campaign 3 has now accumulated enough architectural precedent that implementation should no longer stop for an owner ruling at every behavioral fork.

The purpose of Campaign 3 is to make the ideal character architecture experimentally traversable, instantiate serious competing models, and discover which distinctions are necessary. It is **not** necessary for the architecture owner to personally select the first bounded implementation of every comparison.

## Default rule

**Resolve a decision locally when the accepted North Star, architecture, or Campaign 3 research method already determines the conservative direction.**

Do not request a ruling merely because:

* two candidates make different behavioral predictions;
* one candidate is simpler and another is richer;
* a first bounded control must be chosen;
* a deterministic tie, normalization, or source scope must be specified;
* the richer alternative will remain an explicit comparator;
* implementing the narrower choice first changes the order of experiments.

In those cases:

1. choose the option best supported by existing architectural precedent;
2. record the rejected/nonselected option as a named comparator where it remains meaningful;
3. state the bounded prediction and limitations;
4. continue implementation;
5. do **not** describe the locally selected first model as psychologically final.

A behavioral difference alone is not an escalation criterion.

## Established Campaign 3 decision heuristic

When existing principles clearly apply, prefer the candidate that:

1. **Preserves already-distinct semantic concepts rather than collapsing them.**
2. **Makes the narrower causal claim.**
3. **Uses observer-accessible evidence rather than hidden truth or implementation provenance.**
4. **Uses already-accepted state before inventing new psychological state.**
5. **Avoids introducing a cross-domain exchange rate until a phenomenon requires one.**
6. **Keeps acquisition, retention, recall, workspace, learning, appraisal, attribution, and significance distinct unless an experiment earns their reduction.**
7. **Uses the smallest serious bounded baseline capable of exercising the phenomenon.**
8. **Preserves richer alternatives as explicit comparators rather than implementing them merely to satisfy a desired witness.**
9. **Does not invent a new cognitive mechanism solely because a proposed test assumes one exists.**
10. **Treats canonical ordering, IDs, serialization shape, and representation topology as nonpsychological unless explicitly committed otherwise.**

If one candidate clearly satisfies these rules better than another, choose it and proceed.

## Escalate only when the choice is genuinely architectural

Return for an owner ruling when at least one of the following is true:

### 1. Foundational ontology changes

The choice determines what kind of thing exists in the ideal character architecture.

Examples:

* whether learned association is distinct state from episodic memory;
* whether acquisition has identity distinct from selection;
* whether bodily truth, experienced signal, concern, motive, and Need are separate concepts;
* whether an entity represents cognition, world truth, or runtime protocol state.

### 2. Authority or epistemic boundaries change

The choice determines who owns authoritative state or permits information to cross a boundary.

Examples:

* whether cognition may read hidden physical truth;
* whether protocol state belongs in character memory;
* whether a source/provenance record becomes observer evidence;
* whether one system may mutate another system's state directly.

### 3. A major new causal mechanism is being committed

Escalate when the choice introduces a substantive new psychological causal edge whose existence is not already implied by accepted architecture and whose inclusion would materially constrain later models.

Examples:

* affect → retrieval;
* cognitive use → retention reinforcement;
* standing preference → outcome significance;
* learned causal belief → future prediction.

This does **not** mean every implementation of an already-approved edge requires another ruling.

### 4. The choice forecloses a North-Star phenomenon

Escalate if adopting one option would make an important required phenomenon impossible or would force a later architectural rewrite to express it.

### 5. Two materially different choices remain equally consistent with existing principles

If the established heuristic does not distinguish them and they encode genuinely different views of the ideal character, escalate.

### 6. A proposed reduction would erase a distinction before it has been tested

Do not locally collapse two accepted concepts merely for implementation simplicity. Either preserve both or escalate the reduction.

## Do not escalate these by default

The implementation/research agent is expected to decide locally:

* which already-supported operand makes the first bounded baseline;
* whether to implement the conservative control before a richer feedback model;
* deterministic tie handling;
* structural normalization with no accepted semantic payload;
* exact child versus unrelated sibling targeting when accepted provenance already identifies the child;
* fixture/source sequencing that adds no new psychological mechanism;
* whether a test requiring an unimplemented mechanism should remain OPEN rather than forcing that mechanism into scope;
* first-profile finite bounds and control shapes where the architectural resource domain is already accepted;
* selecting the narrower observer-safe controlled source before attempting a general perception/segmentation theory.

These decisions should still be documented, but they should be documented as **local dispositions**, not presented as architecture-owner blockers.

## Reporting format for locally resolved forks

Use:

**LOCAL DISPOSITION — no owner ruling required**

Then record:

* Selected candidate.
* Existing principle(s) that determine the choice.
* Behavioral prediction.
* Preserved comparator.
* What remains OPEN.
* Any condition that would reopen the decision.

Do not generate a new “DECISION REQUIRED” packet unless the escalation criteria above are actually met.

# Application to the current trial-context question

**LOCAL DISPOSITION — choose A.**

Use **explicitly perceived bounded trial context** for the first four-trial observer-safe source.

This follows existing Campaign 3 precedent and does not require an architecture-owner ruling.

The first controlled experiment needs observer-safe evidence establishing which observations belong to one trial. An explicitly perceived start/end or episode-context cue supplies that grouping without supplying the causal answer.

The architecture should therefore permit:

```text
observer perceives bounded trial context
        ↓
before / motion / after observations
are grouped into that experienced trial
        ↓
contrastive attribution evaluates
whether the focal candidate explains the consequence
```

The context establishes:

> **these observations belong to the same experienced episode**

not:

> **this candidate caused the consequence.**

The attribution mechanism remains responsible for the latter inference and may still be wrong.

### Required boundaries

The perceived context must not encode:

* stroke versus stationary/control classification;
* hidden reserve identity;
* hidden delivery/effect provenance;
* causal success;
* target significance;
* the eventual attributed child address.

Trial membership must come from actually admitted observer-side context evidence, never:

* array position;
* source-only trial ordinal;
* dispatch ancestry;
* hidden truth;
* caller labels.

Loss or absence of that perceived context must be capable of making grouping unavailable even when the hidden source structure is unchanged.

Changing hidden truth while preserving the same observer-safe context and observations must preserve the character-side trial grouping.

### Why B is not first

Observer-side temporal/event segmentation is a legitimate broader candidate, but it introduces a new cognitive mechanism for discovering episode boundaries under overlap, delay, interruption, and ambiguity.

That mechanism is not required merely to execute the first controlled four-trial attribution experiment.

Preserve **B — observer-side event segmentation** as a named later comparator/generalization target.

The first profile's explicitly structured trial source must not be presented as a solution to ordinary unguided event segmentation.

### Reopen condition

Reopen this source decision only when a required phenomenon needs the character to infer trial/episode membership without an explicitly perceived bounded context, or when the explicit-context model prevents a required ambiguity/segmentation behavior from being expressed.
