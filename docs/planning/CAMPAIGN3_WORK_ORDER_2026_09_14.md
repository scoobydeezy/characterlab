## The work order

Items 1–5 come before any further GA registration, allocation or model-packaging work.
Items 1–3 each terminate in a **written artifact that did not exist before** — a verdict
entry or a published corpus manifest. That is the acceptance test for this work order.

### 1. Run the salience-law comparison as pure arithmetic — **FIRST**

This is `GENERAL_ATTENTION_CLOSURE_PLAN.md` closure obligation #2, which has not been
run. It requires **zero allocation, zero registration, zero model packaging and no new
record types.** The mathematics is already written out in that plan:

- **independent:** `x / (1 + x)`
- **shared:** `x / max(B, Σx)` — note the plan's own correction: it is *not* `B·x / max(B, Σx)`
- **hybrid:** important entries exempt; remaining budget is the denominator floor for low entries
- **`RET-001` flat tagging** — retired, executable only as a named negative comparison

Run all four over the same admitted inputs, in exact rational arithmetic, as a pure
component with no identities or state ownership.

Discriminating evidence already exists as corpus obligations: `EXP-007` (same object
changing causal role, attention gating, Need relevance, evidence-aware surprise) and
`EXP-015` (semantic footprint capping achievable association strength — the documented
Habit case where a flat tag capped an edge at exactly `1/2` versus ≈`0.0014` derived).

**Deliverable:** a verdict entry in `VERDICT_LEDGER.md`, in the format of
`VER-C3-PRE-IDENTITY-001`, with every field populated — declared domain, compared
models, exact comparison rule, observed difference, verdict, uncovered regions,
reopen conditions. `UNRESOLVED` is an acceptable verdict. Silence is not.

**Guard rails:** a passing arithmetic kernel closes no expressibility gap, authorizes
no corpus promotion, and establishes no continuous salience law for the public profile.
`MEC-005` stays `CONTROL+CONTRACT`; `MEC-007`/`CTL-004` stay `CONTROL`; `RET-001` stays
retired. Do not infer category priors from identity text — use admitted classification
evidence or an explicitly restricted homogeneous-category control and say which.

The reasoning for holding them contains a category error worth stating plainly:

> **Corpus membership asserts that an obligation exists. It does not assert that the
> obligation passes.**

Campaign 3's declared output is the discriminating-gap list. Holding the gaps outside
the governed manifest keeps the denominator artificially small and leaves `BLOCKED` /
`PARTIAL` dispositions living in a planning document rather than in the governed record

Follow [`CORPUS_0_28_0_SUCCESSOR_MANIFEST.md`](CORPUS_0_28_0_SUCCESSOR_MANIFEST.md).
It carries the prepared entries, assigned `PhenomenonId`s and status. **The digest must

### 3. Write the two owed verdict entries

`EMB-001` and `ATTN-001` both have executed evidence, declared domains, named comparators
and bounded qualifications. Neither has an entry in `VERDICT_LEDGER.md`. A bounded

Write both in the ledger's own format. If the honest verdict is `UNRESOLVED` for want of
a competing model, record `UNRESOLVED` and name the missing comparison — that is a
research result and it is what makes the coverage debt legible.

## Standing constraints for the rest of Campaign 3

**Experiment cadence.** Ship experiments at the cadence you ship allocations. The
threshold rule in `CURRENT.md` is binding: past 50 record types since the last verdict
or corpus member, the next item is an experiment, not an allocation.

**Stage discipline.** Brief §9 has five stages: A make the seam exist, B make the intact
path work, C create a competing model, D replay the same corpus, E assign a verdict.
Campaign 3 has been running Stage A almost exclusively. Every seam from here names its
Stage C competitor **before** allocation, not after.

**Fixture transfer argument.** `src/campaign3/` now contains a substantial visual-search
apparatus — trial panels, marker windows, sweep fixtures, position scenes, spatial
binding. The destination (encoding footprint → later cued retrieval) is correctly aimed
at `PHEN-MEM-001`, `EXP-006` and `EXP-015`. But the GA packet must state, in one
paragraph, **which North Star §30 archetype the fixture stands in for and what the
transfer argument is.** The archetypes are things like "angry person who
disproportionately retrieves prior insults" and "frightened person whose attention
narrows around threat." If that paragraph is hard to write, the fixture is larger than
the research question needs, and shrinking it is cheaper than closing it.

**What is going well, and should not change.** The epistemic discipline has not slipped
once under pressure. Comparators are named rather than deleted. `EMB-001` took the
architecturally preferred interoceptive route instead of renaming `R0`. The second motive
family is genuinely closed. `MEC-005`'s residual pool came back with its exact historical
mathematics. `VER-C3-PRE-IDENTITY-001` falsified its own starting hypothesis. The
`PERMITTED / ATTENDED / ENCODING STRENGTH / ACCESSIBLE NOW` decomposition is the right
frame and should govern the rest of the attention programme. None of this is under
review — only the order in which the remaining work happens.
