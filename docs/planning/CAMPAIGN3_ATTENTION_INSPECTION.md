## Expressibility gaps

1. **Plural candidate production:** accepted SEM can describe relevant objects and
   observed roles, but the frozen EMB factory cannot emit the required over-capacity
   pool. New profile admission must generate candidates from actual frozen SEM and
   companion claims, with exact cardinality and source binding. Authored raw attention
   candidates would evade the experiment.
2. **Temporal scope:** role evidence is too late for current-lane sampling. First
   candidate selects among already permitted/perceived evidence for subsequent active
   processing. Early sensory attenuation is a distinct future seam. Existing recognition
   input is not silently filtered or rewritten.
3. **Encoding/access:** there is no accepted mapping from a selected evidence unit to
   semantic encoding strength and a later accessibility probe. No whole ATTENTION PASS
   is possible from top-K counts or a diagnostic output alone.
4. **Packaging:** exact new record definitions, registration/output closure, typed roles,
   occurrence-domain reuse, finite work and restore need a reviewed symbolic inventory.
   No permanent number or new scheduled phase is chosen by this inspection.

The first draft therefore freezes a proposed research target and explicit candidate
math only. It leaves public integration gated on a complete symbolic profile rather
than treating an exported selection function as an admitted causal path.
