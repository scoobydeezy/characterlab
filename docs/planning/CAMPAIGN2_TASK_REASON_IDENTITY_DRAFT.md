including zero-base exclusion, floor rescue, Avoid sign, tie handling, counter-addressed

Actual cognitiveSignals.ts inspection distinguishes the Phase2.97 commitment-specific

older influence pool. Port the former here. Revision1's proposed alignment-scaled

The only motive channel is Commitment; the referent is the actual adopted task's
SemanticReferentId. No Need, task name, registry order, deadline priority bonus or
successful-action label supplies a second base. Different task origins remain distinct
semantic nuclei even when their complete action candidate is deduplicated.

## Distinct non-identity meaning map

For each actual option o, sum raw P plus Known concern intensity over its actual
task origins, omitting absent motive and unknown concern contributions. Apply the
signed bounded response b(x)=x/(1+abs(x)) once to that sum. This is the option's
unfloored Commitment semantic pressure S(o). Do not reuse role-bounded sums, die
activation, final modifiers or winning probability as this operand. Do not include
standing identity or a named trait. A zero base can leave contextual meaning visible
while still producing no active reason, preserving the two-map distinction.

The global proposed polarity is Commitment→CommitmentFidelity with sign+1, identical
for all tasks, actions and characters. In this bounded model the channel means relative
prioritization of the currently represented adopted obligations. It does NOT measure
successful fulfillment, moral worth, general dependability, effort, or reliability.
Perceived urgency can be wrong; the expression records the character's frozen context.
Choosing the lower-pressure obligation can contribute opposition even though it is
also an obligation. Equal meanings produce zero, regardless of winner or action count.

This interpretation is a revisable reference hypothesis. Reject the competing shortcut
"any chosen task action earns fidelity": it cannot distinguish equal alternatives and
would reward selection from a bare token. Also reject world success as polarity and
feeding identity's own pull back into its new meaning. The corpus must include these
counterexamples before this new source mapping can be qualified.

Preserve the exact historical alignment:

    A(o) = b(S(o) - sum(S(other options)))

Standing raw strength is I, the derived retained identity strength, for each matching
task origin under the fixed identity-channel→Commitment mapping. There is no alignment
factor or extra trait multiplier at this source. This is the exact Phase2.97
commitmentStandingIdentitySignals mechanism, including its same-option/multiple-task
behavior: one signal per distinct actual commitment, not one per action and not a
fractional division by origin count. Duplicate origins reject. The shared qualified
support basis is retained across these distinct nuclei; it does not invent independent
historical evidence. TRC partitions by nucleus before consolidation, as in the control.
Option-level amplification with multiple reasons is an explicit experimental property,
not equivalence to divided or alignment-scaled feedback. Preserve both as comparisons.

## Retained role consolidation and dice equations

Within each option/channel/task triple, split each role into positive and negative
contributions. TRC-004 independently consolidates the two signs; then net their sums
and apply b once. Let these results be B, H and X for base, standing and situation.
If B=0, emit no nucleus before consulting activation; a modifier cannot rescue it.
Otherwise Direction=sign(B) and Relevance=abs(B)+abs(H)+abs(X).
Relevance below the declared threshold produces no active nucleus. It never changes B.

For an active nucleus, choose the greatest declared base-die threshold at or below
abs(B), with faces4,6,8,10,12. If no threshold is reached, use the retained active d4
floor. Convert H and X separately by truncating strength/positiveUnit toward zero,
then clamp to the declared symmetric integer magnitude cap. Reject nonpositive units
at model admission rather than inheriting the reference's zero-unit fallback.

The distribution is sign(B)*(UniformDie(BaseDie)+H_modifier+X_modifier), with sign
applied to the WHOLE sum. Option distributions convolve its active nuclei; preserve
the exact discrete mass and rational probabilities. An available option with no
nuclei has point mass0 when competing with active alternatives. If ALL options have
no active nuclei, emit NoActiveReasons without entering the historical random-choice
fallback. This absence boundary is explicit, not a claim the historical core already
provides it. All distributions and ties require the separate exact arbitration schema.

No calibration is frozen here. Research37/100,1/10 and modifier unit1 exhibit one
possibility; the profile must later commit its constants, admissible history and
work bounds. Integer caps are retained mathematical operations, not state clipping.

## Frozen expression and bounded qualification proposal

DecisionExpression is generated from the actual chosen intent before attempt110.
It retains exact reason context, alternatives, pre-roll probabilities, selected key,
Margin, Contest, ConflictMass, Stake, AuthorshipPotential, resolution mode, actual
draw records/tie break and the unfloored semantic map. Alignment is computed for
every touched channel from that map; current identity is never reread.

Use the historical top-two-by-win-probability pair for both margin and conflict mass,
with canonical candidate-key ordering only to break rank ties. Stake is b of the
smaller reason mass; mass is sum(abs(expected value of each signed reason distribution)).
Contest=1-Margin and AuthorshipPotential=Contest*Stake. These do not derive from the
physical outcome. Exact win/tie and draw-address mathematics remain the arbitration
closure task; the research scripts do not define canonical RNG addresses.

Propose a separate Qualification output at130, always one per live expression. Its
closed verdict is Eligible or Rejected, with a typed rejection reason. Eligible is
scoped to the fixture choice by the exact QualificationContext, not a second tag name.
Eligible requires an authenticated generated autonomous intent, exact frozen operands,
positive AuthorshipPotential, nonzero channel alignment, and the first profile's
exclusion of choice override/coercion inputs. Rejected has exactly ZeroAuthorship or
NoExpressedChannel, tested in that order. It sets no evidence contribution. Eligible sets weight
to the frozen AuthorshipPotential and contribution to Alignment*weight. The expression
also records scope: accepted cost and fear context are NotRepresented, not numeric0.
The result qualifies only this free fixture-choice experiment; it cannot claim general
coercion-, fear- or cost-sensitive authorship. Execution interference is downstream
and cannot retrospectively reject an otherwise eligible intent.

If a later profile introduces choice intervention, fear or accepted-cost semantics,
this bounded qualifier is not admissible there without a successor. An unknown new
context cannot silently pass as absent. A malformed/forged source is an admission
failure, not a valid Rejected psychological result. Rejected is reserved for an
authentic expression that fails a declared qualification predicate.

ZeroAuthorship is reachable through an authentic one-active-option settled resolution;
NoExpressedChannel is reachable with equal non-identity semantic meanings and a
contested two-option resolution. These require actual generated witnesses, not only
constructed records. A rejection is evidence that the bounded qualifier did not
attribute identity meaning; it does not erase the expression or prevent the attempt.

## Identity application and future support

Propose an independently owned identity state keyed by CharacterId plus the fixed
identity channel. Value contains Support, Opposition and canonical qualified-expression
support references with their signed accepted contributions. S0 is empty for the
first intact identity witness. No authored trait flag, initial bonus or accepted
expression list can substitute for the generated history.

At140, apply each new eligible nonzero contribution e using the historical update:
Support'=quantize(Support+max(0,e)); Opposition'=quantize(Opposition+max(0,-e)).
Port the actual lattice D=1000000 and round-to-nearest ties-to-even at each application;
the corresponding numeric profile still requires registration. I=(Support-Opposition)/(K+Support+Opposition),
with K>0, is derived, not another state field. Named traits, if later displayed,
derive from this history and never supply another modifier.

One decision per subject per instant bounds identity application to one target key.
It must nevertheless join the prepared140 stage with exact target preflight, prior
read ownership, disjoint writes, complete rollback and all-stage completion. It may
not execute through ADAPT's authority. No same-instant40 read sees this new state.
At most64 retained support references; a novel65th rejects atomically. Repeated
qualification identity rejects rather than applying twice. No decay or truncation.
Zero contributions do not create support. A nonzero accepted contribution is retained
even if its scalar increment rounds to zero: the qualification happened and duplicate
prevention remains necessary. It consumes one support slot. Retain signed exact raw
contribution alongside the reference so chronological replay, not a commutative sum
of raw values, verifies the rounded totals. The state must also retain canonical
application order; exact representation is still part of state-schema closure.

Qualified output→identity application participates in route/character-learning only
after explicit output/state/occurrence registration. Raw observation, execution truth,
automatic-adaptation input and the chosen action token alone cannot enter this route.
The existing OutcomeEvaluation→CharacterLearningEvidence slice remains unchanged;
this is a separately named later identity-evidence source, not a backdoor into EVID.
