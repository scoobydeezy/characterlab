# Hearsay versus direct-evidence findings — 2026-09-24

LOCAL DISPOSITION. RO-C3-014/019/020 preserve these source and comparison limits.

The source is one named speaker's instructed automatic relay of its latest admitted
belief about one target incident. It is sufficient to distinguish sincere mistaken
testimony from direct perception. It does not establish a new chosen speech act,
deliberate deception, spontaneous reporting or global reputation. Earlier actual-choice
COMMUNICATION/LYING profiles remain preserved rather than silently replaced.

A visible report ticket identifies one testimony from that speaker. Repeated reception
does not provide another retained report, even after a newer ticket. The key is public
message metadata, not a hidden dispatch/observation identifier. A recipient denied the
first transmission may learn from a later received copy. This is bounded duplicate
handling, not detection of concealed common sources or independent corroboration.
New tickets from one speaker are not asserted to be independent evidence.

DirectPriority earns a source-sensitive contrast against LatestEvidence, not a general
truth advantage. A false direct display can keep the direct-priority estimate wrong.
The latest-evidence tie uses direct then report within an instant; that finite order
is explicit and tested, not inferred as a law of cognition. Learned trust, calibration,
source reliability, direct-perception reliability and context-dependent weighting remain
unqualified. The same raw two-channel history is retained by both comparison models.
