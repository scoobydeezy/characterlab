# General attention registry member shape

LOCAL DISPOSITION — no owner ruling required. Symbolic proposal only. Existing
namespace families are reused; no permanent member is assigned by this document.

Name the67 already reviewed stage templates with distinct transition/event/seam
members under `general-attention-`. Names identify fixed implementations, not new
psychological distinctions or schedulable phases. A seam member alone grants no
authority: exact version and full declaration remain model-governed.

The eight accessor members implement the accepted owner/derived view inventory.
Character selectors require actual PRJ/IDN; observer selectors use the admitted
ObserverId. Derived event/body views omit retention metadata and retain provenance.
Available cue gating precedes those reads. Missing initialized leaves reject.
There is no cognitive local-reserve or formation-protocol accessor.

Six authority members cover four distinct cognitive owners, the noncognitive
formation hook and the qualified local physical reserve owner. Exact root/path
authorization must be compiled independently. Existing perception authority may
cover the new observer windows only through an explicit new model authorization;
old authority declarations do not gain these paths retroactively.

The already proposed maintenance-goal kind and qualification predicate remain
distinct from character qualification and from spec/content/holder coupling. One
closed registry envelope kind admits exact declaration schemas; no callbacks.

The machine proposal exhaustively lists these218 members, eight accessor paths and
six owner scopes. This is representational naming of accepted boundaries. Preserve
the alternative of sharing implementation code behind distinct declarations; do
not merge authority or evidence boundaries for naming convenience. Public admission,
exact instances, model bytes and General Attention remain OPEN.
