all three qualified owner leaves, including absent values. All absent means no

not an invitation to manufacture missing history or silently omit candidates.

## Admission, subject and ownership

Each memory-facing wrapper has a required top-level ObserverId. Before PRJ, admission
checks its equality to the carried actual source observer. This preserves the fixed
required-field projection mechanism instead of inventing a nested roster lookup.
Each state reader/writer uses the actual IDN/PRJ result, and compares copied subjects
to it. A character field transported from the join is not a replacement for a writer's
declared projection. Roster reads remain immutable and never grant identity mutation.

Only formation writes EpisodeLedger; only association update writes AssociationGraph;
only presentation update writes PresentationLedger. Seed and reinforce are separate
registered stages under the same presentation authority. Rank and recollect write
nothing. Perception alone owns continuant/event state and the tracking window.

Retention and all three formation/consolidation stages join route/character-learning;
reinforcement participates through its own presentation stage. No stage admits
AutomaticAdaptationInput. This adds a distinct ordinary-memory slice and does not
change EVID's OutcomeEvaluation→CharacterLearningEvidence producer restriction.
No same-event belief read/write or phase150 work is required.

## Output and identity boundaries

RetainedEncoding reuses the selected occurrence as its source address; it is not a
new episode occurrence. Evaluation, intermediate carriers and stored graph/history
values get no extra semantic IDs. Transporting an existing record is not producing
it again. Selection allocates its existing occurrence once; recollection allocates
one proposed recollection occurrence per actual winner, at most2. No-winner branches
allocate none and emit no reinforcement event.

Rank may trace all candidate score rows but passes retained bytes only for winners.
The recollection stage copies those exact retained bytes and score, not the full
ledger. Reinforcement receives actual emitted recollections only; caller-supplied
selection lists and copied historical outputs are not admitted. Its history updates
must correspond bijectively to distinct actual recollection outputs.

Patch-only stages emit no invented state-update occurrence. Their actual patches,
diffs and reads still belong in standard trace160 and the transition result identity
discipline. The final canonical packet must enumerate those result slots as well as
semantic occurrences; the current stage count does not prove allocator closure.

## Remaining blockers to allocation

The source inventory's TrackingWindow alone does not reconstruct all OMT state: OMT
also retains sweep count and used observation/detection ordinals. The public profile
must decide the exact disposition of each before treating restore as expressive.
Globally allocated runtime IDs can discharge within-run occurrence uniqueness only
after exact admission/replay proof; they cannot silently remove the component guard.
Sweep horizon may be determined from the admitted original prefix, but that must be
an explicit producer/profile check rather than an uncheckpointed counter.

The prior TaskConcern acquisition stages, complete wrapper schemas, PRJ registrations,
fixed members, identity roles, total output/result-slot inventory and exact model
cohort remain unclosed. Thus this is a reviewed stage/authority checkpoint, not the
promised final allocation gate. Existing frozen contracts and runtime are unchanged.
