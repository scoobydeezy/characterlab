## First bounded question
Can a character deliberately change a later appraisal by accessing or reorganizing
already admitted context, while preserving the original observation and belief?
Architecture10.2/10.3 and the Control -> Appraisal edge permit the operation; the
existing AFFECT feedback experiment did not implement deliberate reappraisal.
Brief12.6 clause8 is still BLOCKED. This intake changes no coverage disposition.

## Existing evidence and constraints
Use the existing independent likelihood/severity/vulnerability/perceived-control
factors and grounded response path as controls. AFFECT's later feedback and relief
already remain separate from evidence. CONTROL now distinguishes retained goal,
active access and inhibition; its unit-slot rule is a candidate, not the automatic
resource law for reappraisal. Correcting an event-local causal report does not by
itself demonstrate deliberate emotional regulation or causal discovery.

Consult MEC-001/002, MEC-007/009/010, MEC-012..019/022 and P3-001/004/005/008/011.
Retain belief/source boundaries, independent factors, grounded motives, actual
arbitration, immutable expression, relief-not-evidence and strictly later feedback.
No general mental-state label, direct Fear die or universal control cost is admitted.

## Source and operation gate before implementation
Name the particular retained context that can change appraisal and demonstrate its
acquisition before use. A caller-supplied calmer affect value is not reappraisal.
An alternative interpretation must have a declared observer-accessible basis and
may be mistaken; truth cannot choose it. Unknown context must not become known zero.
Identify the operation's trigger, owner, resource/access condition and later receiving
phase. Specify whether it retrieves, maintains or changes interpretation; do not
collapse these operations into an untraced Boolean called Reappraised.

The bounded baseline should change an appraisal operand through that operation,
then use the existing affect and motive consumers. It must not directly overwrite
belief, affect or original observations to manufacture success. If choice is contested,
retain actual inherited arbitration and separate intent from operation execution.

## Required comparisons
Hold original evidence, underlying world event and relevant learned beliefs fixed.
Compare the admitted context operation with NoReappraisal, DirectAffectOverride and
ReliefAsEvidence controls; retain a SameInstantFeedback violation test. Require a
later affect difference, a failed/unavailable-operation case and preservation of the
unchanged belief/evidence history. Keep affect distinct from action: competing reasons
may still select the same action, and a different action is not proof of reappraisal.
Do not use a changed hidden threat or changed goal valuation as the control effect.

Next gate: accept the exact context source and control-operation contract, with
finite bounds, authentic acquisition, owned writes, receiving phases and comparator
predictions, then freeze the public experiment. There is no request for an owner to
choose a formula; escalate only if specifying the source/operation changes an accepted
ontology, authority or epistemic boundary or adds an unsupported causal edge.

RO-C3-011/012/019 own these limits, with010 preserving belief/evidence scope. All
remain at their existing status; no obligation closes. Broader social emotion,
extinction, physiological regulation, rumination and long-run control stay separate.
