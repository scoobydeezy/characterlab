## Why this checkpoint precedes the public profile

The source investigation establishes plural SEM component expressibility but not a
public observer-event profile. Implementing a source by accepting authored cognitive
claims would defeat ATTN's proof. The independently reviewable checkpoint is therefore
the validated selector plus selected-only consumer, with the public producer/admission
boundary kept explicit. This is a useful causal component, not a complete attention,
encoding, retrieval or corpus result.

[Component contract](../formal/ATTENTION_SELECTION_COMPONENT.md) was accepted before
implementation. The kernel allocates no identity and introduces no canonical record,
public input, model manifest, registry or persisted schema. Its audit is diagnostic
in-memory data. Existing canonical binding/claim records are copied to selected reads.
The public AttentionSelection and receipt layouts will still require symbolic and
separate allocation review. This component exemption cannot be used to serialize
unregistered list-shaped public records later.

## Self-review findings and corrections

- Revision1's Cause/Incidental proposal was unsupported by the accepted SEM role
  derivation. Actor/Target/Participant are used here; residual-pool proof is deferred.
- A full selection audit cannot be passed to a selected-only consumer. The actual
  view stores only selected canonical binding/claim bytes, with no pool/SEM pointer,
  observation resolver or archive. Even a known shared observation ID is unreadable.
- SEM requires at least one supporting observation. The initial zero-unit test tried
  to assemble a source with no observation and correctly failed. The corrected test
  has a real supporting observation and zero selectable units. The historical failed
  [test receipt](ATTENTION_COMPONENT_TESTS_REV1.json) is retained; its corrected
  [receipt](ATTENTION_COMPONENT_TESTS_REV2.json) passes. No SEM change was made.
- A zero-unit component experience is not the proposed all-denied public branch;
  the latter must have no reservation and a separately admitted completion.
- Merely checking claim schema is insufficient. The implementation revalidates the
  complete claims against actual unchanged SEM derivation, rejecting omissions,
  forged roles, source mismatch and duplicate semantic claims.
- Reference access is revoked before a consumption attempt, including failure.
  Returned byte arrays and diagnostics are copies; mutation cannot widen authority.

Claims here use exactly `semantic-binding/0.1-candidate#SEM-001G`; existing binding
and experience versions must pass accepted SEM codecs. This clarifies the component
contract's accepted-version statement. Temporary derivation counters are validation
scratch only: no new observation, claim or identity is emitted or allocated globally.
