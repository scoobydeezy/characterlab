## One header and surviving content

Use one AcquisitionOccurrenceId per successful formation. Keep SelectionOccurrenceId
as source provenance, never a storage key or content resolver. There is no additional
MemoryEpisodeId, ChildId, FragmentId or MotionId.

AcquisitionFormationEvidence remains immutable emitted evidence. Its common header
contains Acquisition, Observer, At, SourceSelection and producing seam version exactly
once. Its content is a closed EventContinuant/Interoceptive union. The positive formation
output contains only selected positive evidence and initializes no self-authored credit.

RetainedAcquisition copies that common header once and contains only *currently surviving*
children, wrapped with their current use Boolean and directional presence set. It does
not embed the complete initial formation envelope in addition to survivors. Otherwise
the envelope would retain forgotten siblings and defeat fragmentation. Initial full
evidence remains trace-side under its existing authority and is not a character resolver.

Event fields do not migrate to body groups. A body child gets no visual causal role,

## Safe context and positional evidence

The trial-panel source supplies only its observed glyph and literal stage. The
perception component allocates/continues/ends actual SEM event-files. A retained context
companion must bind one actual source experience, that file, the stage and the actual
supporting panel observation. It cannot be reconstructed from a source table after
forgetting. A body sample remains EmbodiedLevelObservation461 with its existing
ObservationId, observer, channel, time, interval and producer version; signal binding
is a separately governed companion, not an extra field added to461.

This companion is an explicit new admission obligation. The old support-only body
source proposal cannot silently begin populating semantic event-files. The successor
source must freeze the actual context-bearing experience and its complete present
support under SEM-H. One actual opportunity reserves at most one existing ExperienceId;
sharing panel/body support does not allocate a second opportunity or conflate distinct
observations. Conditional reservation must be specified for every positive/empty branch
before whole public shape acceptance.

Motion evidence is computed later from two separately admitted retained positional
views. The source carrier stores neither a synthetic two-position motion nor a copied
earlier view inside the later acquisition. The focal target remains one explicit
candidate-bearing acquisition/child, not both operands or all supporting trials.

## Empty state and independent ownership

The ordinary memory leaf permits a present empty collection after complete loss.
The graph leaf permits no nodes/edges, and neither root's presence implies the other's.
Graph reconciliation removes structurally empty nodes; empty graph does not delete an
episode and surviving episodic content does not manufacture graph nodes. The last-update
instant belongs to graph maintenance, not new psychological node state.

Presentation state remains independently owned and acquisition-keyed, with no body
frequency/recency law inferred from the event model. Exact presentation initialization,
cleanup and body applicability still require final source/owner declarations. A
presentation record cannot be a payload archive or proof that an episode is still live.
