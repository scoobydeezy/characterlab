classification. Scalar identities, optional values, collections, unions, primitive

its run, completed parent, payload or target; the separate expected-event association
still supplies those checks. Similarly, a copied selection or concern occurrence is

while consuming the accepted underlying schemas, transforms and lifecycle contracts.
