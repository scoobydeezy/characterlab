# Interoceptive evidence entering durable memory

2026-09-12. **OPEN architectural decision.** Attribution-gated consolidation and
immediate durable initial encoding remain accepted; neither decision is reopened.

## Concrete question

When a character sees several objects and senses a bodily change, should retaining
that body evidence compete for the **same encoding-selection capacity** as visual
event/continuant units, or pass through a **separate bounded interoceptive encoding
gate** with explicit eligibility and capacity of its own?

This affects what the character can later remember and use as attribution evidence.
It is not a new ID choice, a generic-payload convenience or permission to store every
permitted observation. Both candidates must make excluded evidence unavailable to
later attribution; neither may quietly retain a full observation archive.

## Why the existing contracts do not select an answer

The accepted bounded attention pool groups actual perceived bindings by event-file
and continuant-file and derives role eligibility. Its selected view exposes those
bindings/claims only. The proposed memory retains only positive encoded units.

Actual EMB sensing produces sample461/462 and a support-only227. It supplies no
event-file, continuant-file or role. The installed selector therefore produces an
empty pool for that experience, and selected observation access rejects. These are
executed IA-B1/B2 component findings, not inference from schema names alone.

Architecture §3.2 routes interoception directly into appraisal/motive and §8 separates
episodic encoding from later memory access. Those boundaries support current EMB
pressure without making all body evidence permanently remembered. They do not define
a common visual/interoceptive memory-selection budget or its priority comparison.
Adding a body item to old530 would require a different unit domain, not a fake body
continuant or a manufactured Cause role. Keeping a hidden numeric sidecar instead
would bypass selected-only retention.

## Recommended first implementation: separate bounded encoding gate

Preserve the existing visual event/continuant pool and its exact controls. Add a
separately declared interoceptive encoding gate for admitted body evidence. It must
have explicit source permission, eligibility, capacity/selection, immutable initial
retention, subject ownership and later read authorization. A denied, unavailable or
unselected body sample contributes no retained operand. Source availability alone
does not guarantee memory formation.

This preserves the existing direct pressure path while making persistent body
evidence an explicit acquisition result. The contrastive attribution consumer can
use retained body evidence only when this gate admitted it. Observation identity and
existing subject projection are reused; no invented perceived body object is needed.
The exact body-memory carrier and a lawful noncausal episode/outcome pairing still
require a whole seam, separate allocation and public proof.

The behavioral prediction is that extra visual competitors need not displace body
memory when the independently admitted body gate is held fixed. That is a bounded
research hypothesis, not a universal claim of independent human attention resources.
Shared-resource competition remains a named future comparator, not a retired theory.

## Alternative: shared heterogeneous selection capacity

Admit body evidence as an explicitly different unit variant in a successor attention
contract and make it compete with visual units. Define a common capacity metric,
comparable priorities, tie rules and mixed-modality counterfactuals. No old selector
or old model identity changes in place. Retention remains selected-only for every
variant. The direct transient EMB pressure route need not be altered by this memory
competition, but that distinction must remain explicit.

Here a newly competing visual item can displace body evidence and remove later
attribution support even while the character still experiences transient pressure.
This is a different cognitive prediction, not a larger numeric bound on the same
existing pool.

## Discriminating fixture and preservation burden

Hold body observation bytes, permission, time, initial character and outcome fixed.
Add eligible visual competitors. Compare which body operands survive and whether
the later contrastive assessment is available. In a second intervention disable
body encoding while preserving transient pressure; later memory/attribution must
lose the operand without rewriting that earlier pressure output.

Both candidates also require separate unavailable/zero/denied controls, exact retained
sample bytes, no hidden truth read, no fabricated event/continuant identity, proper
PRJ/IDN, immutable prior episodes and whole-instant rollback/restore. No public vector
is passed by the24 current component/fixture tests or six attribution mutations.

**Requested ruling:** use the separate bounded interoceptive encoding gate first
(recommended), or require shared heterogeneous capacity in the first integrated
model. This determines the new source/retention topology before permanent layouts.
