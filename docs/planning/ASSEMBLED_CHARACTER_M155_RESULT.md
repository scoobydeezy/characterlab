# M155 — recollection reconstructs missing detail from learned regularities

The character can recall an observed appearance accurately while its detail survives,
then reconstruct a missing detail from what it has learned about similar appearances.
That reconstruction can be wrong about an actually displayed feature, and later
observations can change it. It remains
tagged as reconstructed and never rewrites the original observation or stored episode.
