that a registered source be present in that same compiled table. It also accepts only
the predecessor schema registry and exact route inventory. Therefore an ordinary272
appraisal registration naming the new custom workspace source does NOT already work
through that compiler. Do not hide the workspace source in a fake272 record or relax
the old decoder's schema/version checks.

registry or source of provenance. It validates every referenced source/output and
rejects cycles or phase reversal. Prior profiles retain their closed compilers.

controller stage, such as protocol observation121, is identified internally by its
committed controller definition plus declared stage EventType/phase. It need not gain
an invented TransitionKind merely to fit a table column. This follows the existing
fixed bridge pattern; EVID's frozen SEM producer relation is validated separately.
No internal routing label becomes a new permanent identifier or psychological input.

Ordinary generated stages may reuse272/271/274/275/276/277 as embedded records where
their semantics fit. New schemas are visible only to the new exact model compiler.
The producer graph and runtime private parent binding must agree; structural source
compatibility alone never authenticates an event. Registered count and output closure
