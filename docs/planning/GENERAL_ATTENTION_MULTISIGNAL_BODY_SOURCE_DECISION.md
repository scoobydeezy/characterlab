# First genuinely multi-signal bodily source

2026-09-12. **OPEN architectural scope decision.** Signal-level acquisition, separate
body capacity, lifecycle B and attribution-gated credit are accepted and unchanged.

## Why this is now concrete

The public EMB profile has one physically modeled reserve and a permitted level
readout. The grouped gate can select three symbolic groups, but three labels or
resolutions of that readout do not establish three distinct bodily signals. The
required capacity2 versus three-signal experiment needs a real bounded source domain.

There are two materially different ways to supply it: extend the body's physical
state, or extend the sensory mechanisms operating on the existing physical state.
This changes what the model claims exists, beyond codecs or selection arithmetic.
The generic North Star permits both but does not choose these new source meanings.

## Recommended bounded source: three local reserve-level signals

Authorize a successor body profile with three independently modeled local reserve
stocks belonging to one character. They are abstract storage compartments, not named
human organs, new Need meters or three instances of the same readout. Each has an
explicit capacity, anchor/time and nonnegative depletion rate under the existing
accepted reserve mathematics; replenishment targets one declared compartment.

The source exposes separately identifiable observer-side local-level signals through
permitted quantized observations. Each signal may have several bounded resolution
views. Safe signal identity is still explicitly declared by the observation model,
not reconstructed by cognition from hidden compartment keys. This first profile may
map one local-level signal per compartment without establishing a universal rule
that one physical source always means one experienced signal.

Prepared topology:

    one character / three local physical reserve states
      → explicitly permitted local-level sensing
      → three declared observer-side signal groups
      → separate body gate, capacity2 witness
      → selected peer episodic acquisitions
      → governed retained-evidence access for attribution

Physical authoring remains neutral: stocks, deliveries, rates and observation
permissions are inputs; salience, supported attribution and consolidation weights
are never authored per compartment. Equal initial amounts can diverge under different
rates; changing only one replenishment affects only its target stock. Hidden changes
within equal sensed bins must preserve the character-side projection.

This option needs a new exact state/key/source/admission profile, not an in-place
change to the existing single-reserve root or frozen model. Its analytical functions
can reuse qualified materialization, binning and replenishment. The old EMB pressure
path remains its own frozen profile; no three-way pressure aggregation, motive,
cross-signal urgency ranking or final Need ontology is inferred.

## Alternative: distinct sensations from the existing single reserve

Keep the one-reserve physical state. Define several genuinely different observer-side
response mechanisms, each with an explicit sensory meaning and a falsifiable
transduction law. The user's dry-mouth/headache/stomach example illustrates the
distinction, but is not itself an accepted physiological implementation or calibration.

This avoids introducing three local stocks but requires new sensory-response
semantics. Different thresholds or bin widths must not merely relabel reserve-level
measurements as different sensations. The model must state why the outputs represent
different experienced signals and how interventions distinguish those mechanisms.
It may eventually be the richer body model; it is not presently an implemented source
that can be supplied by duplicating channel definitions.

## Prepared discrimination and preservation requirements

For either choice, public capacity+1 must contain actual distinct declared signals,
not arbitrary aliases. Adding a second view of one signal changes its evidence basis
without consuming another slot. Adding a distinct signal can cause exclusion.
No excluded group's bytes may later reappear through trace or a hidden memory store.

Preserve same-time distinct sensing opportunities using authentic ExperienceId reuse,
exact sample censoring, separate source/work/payload bounds, false-attribution
possibility, PRJ/IDN, whole-instant rollback and existing body/attention regressions.
The executed27-test component/identity report and seven grouped-gate source faults
do not pass this public-source burden or select a physiological ontology.

**Requested ruling:** authorize the bounded three-local-reserve successor as the first
multi-signal source (recommended), or develop multiple distinct sensory-response
mechanisms over the current single reserve first. No permanent body-state layout,
signal allocation or public source implementation has been started for either option.
