## Operands and ownership

by one nonlearning probe. Each learning episode has controlled character-side
context: setting Work/Home, significance in {0,1/4,1}, perceived refusal pressure
in {0,1/2,1}, instruction boolean, and movement source Chosen/Forced. Context is
admitted fixture evidence, not omniscient coercion truth. A separate world execution

Forced movement produces no choice, intent, expression, qualification or draw.

Work uses task motive magnitudes1 and1/2; Home uses3/4 and1/4. They are distinct
actual motive contexts with the same two task referents and fixed semantic channel;
this is bounded transfer between these contexts, not discovered cross-domain traits.
No claim of natural inference of significance, coercion or identity direction.

Use the existing exact coverage, dice, arbitration, intent and expression kernels.

option A and opposes B. Meanings exclude standing; feedback cannot author its own

roll/player thresholds1/2. Learning seeds are the run seed, probe seed255 explicitly

## Qualification candidates

Candidate Threshold accepts only actual expressions with significance>=1/2 and
perceived refusal pressure<1/2. Its signed contribution is the inherited exact
authorshipPotential times frozen choice alignment. Zero contributions reject.
Graded instead weights by significance*(1-pressure); it rejects the zero endpoints
but retains partial significance/pressure. IgnorePressure uses the threshold
significance rule while ignoring pressure. Frequency admits every actual expression
with signed contribution +1 for A and -1 for B, ignoring meaning/pressure/weight.
NoFeedback uses Threshold eligibility but removes the later standing effect.
Refold uses Threshold and reconstructs its fold from retained frozen qualifications.
These are explicit competing models, not compatibility flags on a public model.

The selected conservative Threshold baseline avoids granting voluntary evidence
under admitted substantial constraint. The half thresholds and graded law are
candidates, not moral or calibrated psychological laws. New context inference,
observer testimony, represented self-beliefs and biological-source eligibility
remain separate gates under RO-C3-009/014/019/020.
