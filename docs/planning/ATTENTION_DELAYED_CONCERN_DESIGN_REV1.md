## Actual substrate

workspaceOutput381 reads admitted task status and a forecast through restricted
operands. appraisalOutput384 compares that actual available forecast against each
selected task's interval. concernOutput388 separately maps its assessment using the
committed gain; response386 is Unavailable or KnownIntensity. The trusted execution

transformation functions alone do not authenticate arbitrary caller records.

## Proposed smallest same-run carriage

Restrict the first feedback profile to exactly one selected task. No max/mean/sum
across multiple concerns is introduced. Immediately after the actual concern
producer, a trusted adapter projects a narrow carry containing its existing concern
occurrence, actual producing instant, actual workspace CharacterId and the exact
single response386. No new concern occurrence or persistent mood root is allocated.
The carry is generated work at a strictly later committed instant. It is not admitted
as an original input, and no separately executed Run supplies it.

When the later observation selects its observer subject, its actual accepted IDN/PRJ
result must equal the carry's qualified subject before use. The outer adapter verifies
the carry against the registered producer output and same-run scheduled parent chain.
The character-side modulation receives only the response and committed calibration,
never the nested TaskConcern, task archive, state iterator or belief record.
If there is no task/response, the source emits a separately typed NoConcernAvailable
opportunity; it does not mint an Unavailable response occurrence or observed zero.

## Proposed comparison mathematics

For KnownIntensity q in[0,1], the spatial narrowing candidate uses residual pool
P*(1-q), preserving focal weight. It is a task-concern feedback hypothesis, not fear,
threat appraisal or a general stress law. No retrospective changes to the producing
appraisal, selected history or episode bytes occur. A DisabledFeedback model keeps
P. The source and actual concern production remain identical across that ablation.

For later retrieval the proposed contrast keeps omegaB=1 and sets omegaA=1+q, changing
the weight of current associative pull relative to presentation accessibility.
DisabledFeedback keeps omegaA=1. This does not change W, presentation times, prior
encoding, importance or any belief. Fixed candidate bounds and exact rational math
are retained; the modulation is traced separately from both source components.

Unavailable response uses the explicitly declared BaselineWithoutAvailableFeedback
branch. Its numerical policy matches disabled feedback while its unavailable status
and source provenance remain distinct. It is never relabelled KnownIntensity0.
Known zero remains an observed producer result and has that distinct trace.
