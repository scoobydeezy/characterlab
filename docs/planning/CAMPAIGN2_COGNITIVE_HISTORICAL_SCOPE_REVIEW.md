# Cognitive historical mechanism scope review

Status: internal design review; runtime port and experiment verdicts remain open.
Authority: REFERENCE_MECHANISM_LEDGER, North Star, Architecture and Research Brief.

The proposed three SourceRole values match the actual Phase2.97 reference type in
reference/src/model/reasonNucleus.ts. Its comment explicitly excludes ContextModulating
because no fatigue/intoxication/time-pressure source was implemented. The mechanism
ledger nevertheless preserves that fourth architectural role as a PORT obligation.
These are different scopes, not a reason to silently delete the ledger obligation.

For this first task profile, preserve the actual three-role reference pipeline.
ContextModulating has no current source, transformation or quantitative definition
and is not admitted under an invented tag or folded into SituationalEvidence. Retain
it as a future source/role extension requiring an explicit contract and experiments.
This bounded exclusion is not retirement, implementation, or whole MEC-013 closure.
The future role must remain separately traceable when introduced.

MEC-011 availability versus relevance is exercised through retained instructions and
independent base/forecast/workspace controls. It is not a world-efficacy planner.
MEC-012..016 retain actual nucleus grouping, sign-separated aggregate consolidation,
bounded role sums, active floor and exact die/modifier/arbitration mathematics.
MEC-017..019 preserve frozen pre-outcome meaning, qualified ordered identity evidence,
raw standing feedback and intent/attempt/outcome separation. MEC-020 retains the
qualified task lifecycle and selected live commitments as non-Need generating sources.
MEC-022 requires exact model/version and full historical source retention at expression.
Each remains subject to current-source port tests and the required historical controls.

MEC-021 multi-participant salience attribution remains CONTROL/CORPUS, outside this
one-holder measurement-memory path as already recorded by its accepted memory seam.
No participant weighting is inferred from task origin count or observer ownership.
Need primitives, fear/cost qualification and general context modulation remain later
sources. Their absence does not permit relabeling a task pressure as those mechanisms.

SUB-007 uses aggregate union-max weighted Jaccard, including its subset limitation;
the pairwise-max predecessor stays retired and is a detecting substitution. SUB-008
uses actual trace bytes and prefix replay. SUB-009 remains the accepted addressed RNG
and coupling-control obligation. The first cognitive public profile excludes externally
provided coupling maps; first-boundary comparisons must prove equal natural addresses
or state that subsequent draws are not paired. A later map-enabled profile needs its
own admission and persistence proof. This does not retire the accepted substrate map.

Required current-source experiments include evidence aggregation substitutions,
modifier rescue/exclusion, all die bands, all resolution modes, exact ties, positive
and opposing acquired identity, quantized fault-line crossing and initially empty
generated feedback. Historical components can supply differential controls but cannot
be imported into src or substitute for a missing active implementation. No new shape
verdict alone passes these experiments or completes Campaign2.
