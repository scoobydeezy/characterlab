## Limits

These are supplied-state controls. Compact metadata cannot establish when an older
child earned its tags; public commit/read-point authentication is still required.
Rejecting fresh protected formation is only one necessary temporal check. No actual
concern→attribution-target→credit→later-retention public chain is passed. No corpus,
numeric schema, result identity or save/load is promoted. Significance and use state
remain separate from MEC-010/EXP-006 accessibility and original MEC-007 encoding.
