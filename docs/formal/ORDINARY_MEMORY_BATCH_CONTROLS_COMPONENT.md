# Ordinary memory batch retention controls

`ordinary-memory-batch-controls/0.1-candidate`,2026-09-13.
LOCAL DISPOSITION — no owner ruling required.

Separate preparation entries run the already accepted age-only, use-only and shared
protection comparators through the common significant formation/protocol owner and
ordinary memory batch. The default remains significance-first. Only the retention
kernel differs; no caller-supplied function is admitted by the exported API.

Every kernel sees original B0 metadata plus fresh uncredited children. Use/significance
applied in the current batch overlays actual survivors afterward. All controls validate
the same protocol coverage, fresh initialization and one-use result. Actual survivor
identities determine complete loss, including committed formation followed by loss.

Controls preserve ignored metadata on survivors. Age-only does not erase use or
significance, and use-only does not erase significance. Their predictions therefore
test ranking dependence without also changing the state carried into future instants.
Each kernel retains its accepted canonical tie/order and independent per-kind bounds.

The discriminating witness has old significant child1, newer used child2 and fresh
unprotected child3 with one slot: significance-first retains1, shared/use retains2,
age-only retains3. At full capacity their retained metadata agrees. Same-instant credit
cannot rescue a child under any control. Public input authentication, owner writes
and persistence qualification remain OPEN.
