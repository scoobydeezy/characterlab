## Comparison laws
For each same-category prior imprint, count equal and unequal feature positions
known in BOTH observations. Compared = equal + unequal. Similarity is equal/compared
when compared>0 and otherwise absent. Expose all three counts and surviving detail
separately; similarity is not calibrated confidence or identity probability.

1 PartialMax: take maximum known similarity. Positive maximum means Familiar;
if any maximizing imprint also has an unequal compared feature, FamiliarDifferent.
Zero means Novel. No same-category imprint means NoHistory; existing imprints but
no comparable features means Unknown. No admitted current category means NoPercept.
All maximizing source refs are retained in acquisition order: ties assert no identity.
2 ExactOnly: same comparisons, but only an imprint with two equal features qualifies
as familiar. Other known comparisons yield Novel. A serious stricter alternative.
3 DetailRequired: same PartialMax rule but only imprints retaining peripheral detail
can contribute to the maximum. This comparator confounds familiarity and recollection.
4 MissingAsFalse: replace absent signature fields with false before comparing. This
violates missing/negative evidence separation and can invent familiarity.
5 TruthIdentity: compare current hidden world identity with hidden identities at the
encoding times of same-category retained imprints. Maximum is1 if any identity matches,
else0; familiarity follows this hidden equality. Explicit epistemically violating
comparator; ordinary models never perform this lookup. Feature comparisons remain
visible so the unearned override can be diagnosed. No identity value is exported.
