## Meaning and authority

A permitted outcome from a real assembled attempt remains in knowledge1000/3.
The causal query names an admitted task and its visible attempt-time ticket.
No matching prior observation means Unknown; observed success means NotFailure.
Failure alone means Ambiguous. The queried outcome is never rewritten.
Obstruction and execution limitation are an explicitly closed competing pair,
not exhaustive natural-world causes. Learned performance confidence, skill,
identity, Values, intent and physical success remain separate.

Port JointDiagnostics: initial odds B:L=1; latest observed movement and resistance
each multiply odds by3 for true,1/3 for false,1 for absent. Normalize to
pB=odds/(1+odds),pL=1-pB. Equal retains Ambiguous. A first-admitted receipt per
attempt wins, including conflicting repeats; independent receipts update latest
channels without multiplying repeated equal support. Foreign tickets do not
update the queried attempt. Missing differs from false. MotionOnly,OutcomeOnly,
NoLearning remain original controls, not scenario switches in the reference.
R3 first-use lock: these are engineering defaults, no superiority verdict.

The same phase50 appraisal stage consumes strictly prior inferred weights.
ProtectRoute selects pB; RepairCapability selects pL. Existing SplitExposure
uses severity/vulnerability1,control0, as in the original component. Unknown/
NotFailure has no causal appraisal. Changing the current diagnostic goal cannot
change knowledge or inference. This introduces no reason die or action policy;
an eventual mitigation-choice connection requires its own supported mapping.

[tag, task, attemptTicket, receipt, visible, motion?, resistance?], optional
Boolean lamps encoded as [] or Boolean. At14 the generated safe report contains
[tag/observation, observedAt, task, attemptTicket, receipt, motion?, resistance?].
Denied/empty displays emit no observation. No world cause, capability or truth
field enters this report. Visible ticket/receipt marks are fallible display
claims, not hidden source ordinals or proof that an attempt exists.
Natural telemetry recognition is outside this bounded channel.

display. At most16 diagnostic displays, one per instant, and16 query contexts.

[tag/context, task, attemptTicket, goal], ticket<=current time.
Only admitted tasks and the two named goals; no authored latent probability.
An input at10 cannot be emitted by a runtime handler; generated14/130/140 events
must be exact bound children. Appraisal50 consumes earlier committed evidence,
even when a current diagnostic observation14 already exists.

Knowledge owner1000/6 stores [tag, list(safe observations)] per admitted task,
capacity16, strict time order, append-only; denied reports are absent. It shares
the existing knowledge authority and state adapter. No new state wrapper.
Inference folds this journal filtered by task/ticket, ignoring duplicate receipt
marks after their first occurrence, and joins the actual1000/3 outcome.
