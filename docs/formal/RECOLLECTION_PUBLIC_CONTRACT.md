## Source, owners and phases
One observer sees up to8 labelled cards/events in two controlled displayed categories.
Each has one Boolean peripheral detail. Apparatus labels establish episode identity;
they are not inferred people or truth handles. Displayed detail may differ from truth.
Category and detail access are separate: no category access admits no episode; missing
detail is absent, not false. No original injects learned state or reconstructed output.
All episodes are routine, equally low-importance content in this profile. The retention
law is a candidate, not an earned general importance or defining-memory law.

At most12 originals at increasing integer instants1..16, kind0 probe or1 episode.
Episode labels1..8 are unique on kind1; kind0 has label0. Query0 means no recall;
query1..8 is an identifying cue and cannot create an unobserved episode. Each instant:
recall40 -> source110 -> observe120 -> consolidate140. Recall uses prior committed
imprints and category summary only. Source emits research-only truth. Observation
projects only admitted fields and always reserves a fixed occurrence slot, including
when empty. Consolidation is sole writer: memory root1045 stores1044; summary root1048 stores1047. One consolidation authority
owns both leaves. These are distinct state and outputs even with one transaction.

An observed episode encodes source observation ID, time, label, category and optional
detail. Consolidation removes the detail, retaining the identifying fragment, whenever
current time - observation time >=3, except KeepDetail. This is event-sampled after
current recall, never retroactive. It actually removes detail from character state;
the immutable original observation remains in research trace, unavailable to recall.
No hidden full-episode cache or archive recovery is permitted in the baseline.

Each new observed known detail contributes once to the corresponding category's
false/true counts and list of unique observation references. The summary contains no
per-episode detail map. It is acquired from observations, not reconstructed recall.
Recall and fragmentation add no summary credit. Missing detail contributes none.
Summary and episode are never summed as two votes about the recalled episode.

## Candidate laws and reconstruction
1 ModalFill: if an addressed imprint retains detail, return it tagged Retained.
If only the category fragment survives, fill the missing detail from that category's
strict majority of acquired known details and tag Reconstructed. Equal counts or no
known samples leave a FragmentOnly result with absent detail. This is an uncalibrated
category default, not a probability or identity recognition. Retained detail wins even
when it contradicts the default. Unknown episode returns Missing, never a stereotype.
2 FragmentOnly: never fill lost detail; a serious non-reconstructive alternative.
3 KeepDetail: preserve encoded detail forever in this finite horizon; same recall rule
as ModalFill for details never observed. This distinguishes retention from reconstruction.
4 TruthRestore: after loss, read original hidden world detail by label and present it
as reconstructed. Explicit epistemically violating comparator, never the baseline.
5 ReencodeGuess: ModalFill plus storing a reconstructed guess back into the episode's
detail slot at consolidation, without provenance marking. The next recall presents
the guess as retained; this is the explicit provenance-violating comparator.
Consolidation first fragments, then applies this comparator's prior recall guess,
then appends new observations. Summary never gains recall credits in any candidate.

Recollection exposes Missing0/Retained1/FragmentOnly2/Reconstructed3, optional category
and detail, original episode reference and (only for a guess) category support refs.
It remains event-local; no generic belief or affect consumer is qualified here.
Repeated recollection may change with genuinely new category evidence while the
surviving episode remains unchanged. It must not rewrite earlier observation/output.
