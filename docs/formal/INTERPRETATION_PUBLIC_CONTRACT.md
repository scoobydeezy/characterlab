## Competing models
1 ContextualMean: use observed context, retain every received interpretation, exact mean.
2 LiteralMean: always assume convention1, including when no context was observed;
serious simpler alternative, faithful in convention1 but wrong for convention2.
3 IntentOracle: for a received glyph use the private intended assertion regardless
of observed context; explicit observer-boundary violator, never a baseline permission.
4 NoLearning: lawful contextual interpretation, no recipient state update.
5 LastInterpretation: same contextual history, latest available interpreted Boolean;
serious alternative to accumulating all interpreted samples.
6 NoInterpretation: retain received glyphs with absent meanings; interpretation ablation.
Speaker learning is unchanged across models. No confidence, source trust or fusion law.
