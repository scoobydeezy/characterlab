# Recall partition projection

`recall-partition-projection/0.1-candidate`, 2026-09-13.
LOCAL DISPOSITION — no owner ruling required. Trusted component scope.

The common episodic owner retains event and interoceptive acquisitions with their
independent use and directional-significance metadata. An available-cue reader
projects only its admitted partition, acquisition identity/time and surviving
child evidence. Use protection and outcome-significance directions are omitted
before the ranker receives its operands. No ranking weight is inferred from them.

The owner value is validated before filtering, including the other partition.
Only earlier committed acquisitions are admitted. Returned views are detached;
projection does not mutate memory, history, protocol state or learned associations.
No acquisition identity, retained child or evidence view is synthesized.

This is a projection of the existing state, not a new persistent partition or
provenance system. Event-key translation into canonical perceived identities
remains the existing adapter's responsibility. Public PRJ/IDN, exact accessor paths,
canonical return-shape validation and absent-cue no-read enforcement are upstream;
this component is not public read-boundary qualification. The existing recollection
producer invokes its reader only for available cues.
