# Ordinary memory batch

`ordinary-memory-batch/0.1-candidate`, 2026-09-13. LOCAL DISPOSITION — no owner ruling
required. Implements the accepted common-B0 and prior-committed retention rules.

Consume one complete subject-owned batch: B0 significant memory and protocol,
actual formation admissions/results, current qualified use results, current qualified
significance credits, and the admitted per-kind retention budget. Every B0 acquisition
predates the current instant. Actual source, subject and operation authentication
remain upstream; this component grants no public mutation authority.

Validate every use result against B0 independently; duplicates inside one result
reject, while separate real results can refer to the same child without extra binary
credit. Validate all significance against the same B0 children. Fresh acquisitions
cannot receive current use or significance through this batch. Source replay, fresh
content and unearned fresh metadata still use the existing formation validator.

The existing significance-first formation settlement computes retention from B0
metadata and uncredited fresh children. Overlay this batch's validated metadata only
on the resulting survivors. A currently credited child may still be lost, and lost
children are not resurrected. This is required by the prior-committed read point;
it does not introduce a new tier law. On a later instant, committed credits participate
normally. Old payloads and acquisition times/identities remain unchanged.

The actual survivor result owns formation-protocol reconciliation, including fresh
formation followed by complete loss. The batch snapshots its inputs and publishes
only through its own one-use result. A different batch, copied token, replay or closed
result cannot commit it. Actual scheduler commit, patch authority, canonical typed
addresses and complete-prefix persistence still need public qualification.
