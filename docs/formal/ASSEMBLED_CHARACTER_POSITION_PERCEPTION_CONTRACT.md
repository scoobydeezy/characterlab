# Assembled position/context perception — 0.1 candidate

M49 rules/registry0.50 adds slot33 [assembled-position-perception/0.1,
perception-window-authority-definition]. Existing33 slots retain their semantics.
This is a shared perception package of the retained-attribution connection, not
permission to synthesize causal support or skip episodic access.

Source payload: [tag, position, panel]. Position is unsampled[] or
[x,y,glyph,visible,permitted]; panel is unsampled[] or [glyph,stage,visible,permitted].
Coordinates/glyphs are integers0..7, stage is Before/Motion/After, booleans strict.
At least one source sampled. Times1..100 unique; max10 position,16 panel samples.
Reuse original position-display and trial-panel source filtering. Truth source stays
in its source trace; later payloads contain only actual permitted observations.
No source-supplied file ID, candidate identity, group membership or causality flag.

Current lane executes Observation10, TrackingAndSegmentation11, Binding12 and
ExperienceFreeze14, using accepted SEM A/C/H functions and runtime occurrence IDs.
Position record, track/binding, context and semantic experience all join actual
observation IDs. No scene identity is inferred from coordinates. Role evidence is
unresolved unless actually supplied by a future admitted observation contract.

Port marker-window policy for one current marker: unique same observed glyph in the
last sampled visual window continues its track; observed absence clears that match.
Unsampled visual leaves it intact. All tracks/counters remain in shared SEM241.
Port panel-window policy: Before or changed glyph ends the prior context; matching
Motion continues; After returns its context then ends it. Observed absence ends;
unsampled panel with an active context and a sampled visual source rejects. Visual
without present panel gets its own transient event. Shared SEM242 may contain other
active social events, which this operation must never end or treat as its context.

Perception authority owns a new241/3 map keyed [ObserverId,channel], with allowed
channels position and social. Position window stores only last sampled marker
observation/glyph/file, current panel glyph/file and their clocks. Social window stores
only last actual social track; continuity must not pick the newest cross-channel file.
No window carries its own counter or source archive. Supplemental authority manifest
is committed in slot33; original seven SEM leaf definitions remain unchanged.
All writes are scoped to authority/perception. Initial window/SEM learned state is
forbidden. Counter ceiling64 is a bounded engineering extension, not a cognitive law.
Counters advance only with new files, never decrement/reuse; active event membership
may be removed per the original SEM registry. Old bundles retain append-only bounds.

Interpret visual records through shared C1 mechanisms. Freeze publishes typed227
experience and a detached safe report of observed position and bound context. It does
not yet create346 episodes or causal beliefs. Position/context-to-retained attribution
is Deferred (component not integrated), affecting BRIEF-12.3-2/-5. The next package
must carry actual frozen records into existing episodic retention/recall/workspace;
no archive scan or authored intermediate is authorized by this package.

Controls: compare standalone marker/panel window policies on the predeclared four
