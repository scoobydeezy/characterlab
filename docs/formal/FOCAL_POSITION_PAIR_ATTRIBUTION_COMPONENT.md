# Focal position-pair attribution component

`focal-position-pair-attribution/0.1-candidate`, 2026-09-13.
LOCAL DISPOSITION — no owner ruling required. Enforces the accepted requirement that
the designated focal episode be one of the two computed stroke trials.

The coordinator binds a focal trial index0..3 from exact recalled consequence grouping
before evaluation. The index is transient addressing of the four admitted operand
groups, not an identity, ordering inference or psychological selection mechanism.
Invalid indices reject before projections. The actual retained position-pair consumer
performs its unchanged evidence reads and contrastive assessment. Supported is retained
only if the already consumed focal motion is the (0,0)->(1,0) stroke. A designated
stationary control returns Unavailable, even if the overall contrast is supported.

The focal check uses the same detached positions already consumed by the assessment;
it neither rereads memory nor consults the source schedule. Consumed-child accounting
is unchanged: full contrastive evaluation can earn use for all operands while the
focal result remains unavailable and earns no outcome significance. Early failure
still credits only actually consumed operands. This is an attribution boundary, not
a new reward, appraisal or truth comparison.

The existing unfocused position-pair and older retained-attribution components remain
controls. Public focal opportunity/PRJ/read admission, actual result occurrence and
memory-owner credit binding remain separately required.
