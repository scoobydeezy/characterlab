# Retained context grouping

`retained-context-grouping/0.1-candidate`, 2026-09-13. LOCAL DISPOSITION — no owner
ruling required. Narrow component realization of the accepted perceived trial rule.

The public retained-child inventory contains a PerceivedTrialContextEvidence
companion, not the original full SemanticExperience. Grouping therefore consumes
only those already bound companions: experience identity, perceived event-file,
panel observation identity and its observed stage/time/glyph. It does not reconstruct
a synthetic SemanticExperience or resolve an old identity against a source archive.
Structural copying does not authenticate a recalled child; source binding and actual
winning recollection admission remain the outer adapter's responsibility.

The existing two-position rule is unchanged: exactly one Before, two Motion and one
After in the same observer event-file, ordered by observed time. Position ordering
is not derived from identity ordinals or input order. Missing or excess role members
remain unavailable; duplicate experience identities and inconsistent chronology
reject. The first grouping input contains at most16 distinct experience companions.
The first trial profile has one selected candidate/view per source occurrence;
multi-child/view context deduplication is not silently inferred by this component.

Grouping reads no memory root itself, grants no use/significance credit and mutates
no owner. Its returned identities select only the already admitted recalled operands.
The full-experience component remains an explicit differential control. This removes
a representation dependency, without a new identity, causal rule or provenance system.
