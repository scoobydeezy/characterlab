# Body acquisition evidence producer

`body-formation-evidence-component/0.1-candidate`, 2026-09-13. LOCAL DISPOSITION
— no owner ruling required. Implements the body branch of the proposed phase130
AcquisitionFormationEvidence lifecycle. Acquisition namespace and canonical record
allocation remain gated by whole public closure.

The producer consumes the actual one-use contextual body selected capability.
Nonempty selected groups allocate exactly one symbolic acquisition occurrence from
the supplied shared runtime allocator. Its header preserves observer, acquisition
time and the actual source-selection identity. Its content contains only selected
signals, safe sample bytes and each view's bound context companion. It does not
carry the full source experience or any unselected sample or truth resolver.

An empty selection produces no evidence, acquisition or owner work. The already
completed selector still exists and must be enrolled by the independent protocol
hook. The output is provisional evidence, not a statement that memory committed.
The140 ordinary-memory owner must consume the exact admitted producer output and
reuse its identity. This component mutates no persistent family or protocol value.

Allocation failure leaves no evidence. Its consumed capability is not reusable;
whole-instant retry reconstructs selection from the admitted prefix and rolls back
the runtime allocator. A local capability is not a save/restore certificate.

BF-A freezes selected multi-view preservation and one acquisition per selection.
BF-B freezes capacity-zero/unavailable no-formation behavior. BF-C rejects raw,
forged and reused inputs. BF-D protects failed allocation and detached evidence.
These are component controls, not actual phase/route/PRJ/public-owner qualification.
The generic consequence OutcomeEvaluation→CharacterLearningEvidence path is unchanged.
