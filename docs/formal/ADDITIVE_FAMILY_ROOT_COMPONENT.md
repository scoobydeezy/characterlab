# Additive family-root classification component

`additive-family-root-component/0.1-candidate`, 2026-09-13.
LOCAL DISPOSITION — no owner ruling required. Representation-only component contract;
canonical descriptor allocation and public model activation remain OPEN.

The frozen Campaign2StateFamilyRegistry284 maps each family to one definition285 and
storage286, whose materialized variant names one root. Preserve that representation
and every frozen model. A successor may add an explicit list of additional physical
root extents to already declared logical families. It does not rename ordinary memory
into a parallel psychological family merely to fit the old record.

Inputs are trusted decoded descriptors: declared families with their exact route,
base roots and leaf-family/field maps; additive roots name one of those families and
their own leaf-family/field map. No additive route override is allowed. At most32
families,32 total physical roots and16 fields per root. Root IDs, field IDs and leaf
identities must be positive/canonical and unique at their governed positions. A root
belongs to exactly one family, and a leaf-family identity maps to exactly one physical
root/field within that family. Nonmaterialized families may have no base roots.

RuntimeProtocol roots form a separate disjoint list. They have no family or learning
route. The classifier returns Family(family,route,leaf) for a declared field, or
RuntimeProtocol for a declared protocol field. Unknown root/field rejects. Inputs and
returned identities are detached, so modifying a construction object cannot change a
running classification. Descriptor order cannot change results.

Classification is not a read or mutation grant. Existing StatePath/StateKeyGrammar,
authority, exact read/accessor closure and route/write-family checks still apply.
In particular no Family result permits cognition to read physical truth. Every
cognitive direct or recursively derived accessor must exclude protocol paths through
its separate admission check. Existing authorities are not automatically widened by
an additional family root; each new leaf needs its exact disjoint authority coverage.

The first intended applications preserve346's measurement memory while adding general
episodic content/presentation roots, and preserve373's task commitments while adding
maintenance-goal state. Associations remain their already accepted distinct family.
Protocol governance never enters one of those families. No new cognitive edge, phase,
identity family, persistent state value or reduction is introduced by this classifier.
