# Selected spatial encoding capability

`selected-spatial-capability/0.1-candidate`, 2026-09-13. Local component separation.

Preparation consumes the actual one-use selected view and validates the existing
spatial SEM source join. Only selected binding/claim bytes and the corresponding
detached spatial witnesses and role factors enter the resulting private capability.
No observation object, full experience, track array, unselected witness or resolver
is retained. Preselection peripheral count remains the accepted bounded scalar witness.

Preparation reuses the existing selected encoder to extract its exact role factors;
that helper's nonspatial strengths are discarded. The selected spatial encoder alone
applies the chosen spatial budget law. This does not create an additional encoding
record, occurrence, learning transition or persistent state.

The downstream encoder accepts only the actual capability plus its explicit law.
One attempt consumes it, including a failed law check. Closing an unused capability
discards it. Caller mutation after preparation cannot change its evidence or factors.
The existing immediate convenience composition preserves outputs, while the split
API makes the proposed selected-only boundary executable without granting public
source authentication, canonical transport or persistence authority.
