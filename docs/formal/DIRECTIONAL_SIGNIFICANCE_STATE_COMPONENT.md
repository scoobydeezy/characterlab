# Directional significance state component

2026-09-13. `directional-significance-state-component/0.1-candidate`.
Component shape accepted by primary-agent review under autonomous authorization.

Each surviving child carries outcomeSignificanceDirections, a finite set represented
in component output order MovingCloser then MovingFarther. Valid stored sets contain
at most two unique exact tags. No other tag, count, magnitude, timestamp or concern
value is admitted. The field is independent of useProtection and acquiredAt.

applyQualifiedSignificance consumes a trusted current owner context plus at most64
already-qualified credit projections. Each names observer, character, direction and
explicit targets. Validate every credit and current state before returning anything;
reuse attributed-child-boundary-component for subject, extant-child and duplicate
normalization. Insert direction idempotently at each target. Repeated credit changes
neither bytes, acquisition time nor useProtection. Output state is detached; there
is no mutation to caller state, persistent owner or provenance history.

These inputs are NOT authenticated public results. The missing actual attribution
target + concern qualification + committed-result join is a mandatory future gate.
This component only implements the supplied-qualified-credit state algebra.

fragmentSignificantChildren consumes an already accepted explicit child-loss plan
and capacities. It uses actual fragmentation and reattaches metadata only to its
survivors. Lost-child significance is removed with the child; no metadata archive
or resolver remains. Newly formed children must start with an empty set through
the future authenticated formation owner, not inherit by semantic key. This component
does not itself prove that public formation initialization.

SharedSignificanceBitControl projects a validated direction set to nonempty/empty
for an explicit reduction comparison. It is not the intact state and performs no
write. No survival ordering follows from any tag, set cardinality or use bit.
Goal changes cannot erase earned tags through this API; historical result provenance
remains separately governed. Absence of a tag asserts no complete historical fact.
No public schema, numeric allocation, memory authority or persistence is added here.
