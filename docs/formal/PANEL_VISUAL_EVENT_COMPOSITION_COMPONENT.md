# Panel/visual event composition component

`panel-visual-event-composition/0.1-candidate`, 2026-09-13.
LOCAL DISPOSITION — no owner ruling required. Implements the visual fallback already
required by GA_BODY_SOURCE_BRANCH_CLOSURE_REV2, at supplied-observation component scope.

Reuse the panel perception owner's one actual SEM event-file state and counter. A
present visual event with a present panel uses the panel's exact event detection and
transition. Two different event detections for that combined event reject. Separate
panel and visual observation outputs retain distinct observation identities.

If the panel is actually unavailable, close any prior perceived trial window as before.
An independently present visual observation then creates and immediately ends a fresh
SEM event file using that same owner counter. It supplies lawful visual binding scope,
but no trial-context companion or inferred Before/Motion/After stage. Reappearing panel
content gets a later fresh file and cannot restore the missing trial context.

This conservative one-observation fallback preserves the qualified finite attention
source's fresh-event behavior. Persistent event segmentation without a panel remains
a separate comparator/generalization. Continuant tracking is separately owned and is
not reset or inferred by this event-file operation. The present visual detection is a
trusted component input; it does not establish public positional/role evidence by itself.

Validate observer, equal instant, distinct nonreplayed observations and exact detection
binding before publishing any state. At most16 sampled panels and16 accompanying
visual observations are admitted. A missing visual observation emits no fallback.
The API requires an actual sampled panel result; an unrequested panel must not be
represented as Unavailable. Body-only opportunities use their separate adapter.

No new event identity family or counter is introduced. No body key, causal label,
attributed target or truth resolver enters the result. Public source completion,
combined experience reservation and canonical state/save admission remain OPEN.
