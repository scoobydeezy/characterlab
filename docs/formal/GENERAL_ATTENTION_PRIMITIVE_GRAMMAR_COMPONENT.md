# General attention primitive grammar

`general-attention-primitive-grammar/0.1-candidate`, 2026-09-13.
LOCAL DISPOSITION — no owner ruling required. This consolidates existing primitive
domains from the symbolic carrier inventory; no record or identity is allocated.

Canonical encoding is checked before primitive-domain validation. Rational aliases
use exact numerator/denominator comparisons. Generic Rational remains unrestricted;
the maintenance-goal field validator separately owns its closed0..100 endpoints and
Lower<=Upper relation. A field-specific domain must not globally narrow Rational.

Instant is signed nonnegative int64. OriginalAddress is unsigned, with exact run-list
membership checked separately. FieldOrdinal is positive unsigned, with actual schema
membership checked separately. Glyph/Cell are unsigned0..7; ViewOrdinal0..2;
ViewCount0..3; first-profile SourceBound is exactly32. The ten calibration count/scale
aliases retain their declared bounds. OutputCount is0..32, and PhaseOrdinal admits
only the67-template graph's phases, including110 and excluding150.

LatticeMass requires the committed graph scale and lies in0..scale; the scale is1..1000.
VersionText requires exact membership in the stage's compiled admitted-version list.
Neither derives context from the value being checked. Boolean and False remain
canonical booleans, not unsigned tags. Unknown primitive names reject.

This function receives decoded canonical values and trusted compiled context. It is
not a data-only public factory, a record validator, a role/subject check, or a complete
model validator. Record relations, enum layouts, union membership, identities,
stage-specific version binding and source provenance remain separate required gates.
